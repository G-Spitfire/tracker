# WordScene · UI Kit 1.0

Статус: **согласованный дизайн-стандарт** (6 ноября 2026).  
Область применения: `wordscene-17-lab/`.  
Этот документ описывает целевое оформление, **а не утверждает, что все параметры уже реализованы в CSS**. Текущие расхождения перечислены в [UI_AUDIT.md](./UI_AUDIT.md).

## 1. Принципы

1. Сохраняем узнаваемый стиль **Paper**: тёплый фон, мягкие поверхности, маяк и фирменные цветные иллюстрации.
2. Значение цвета и тип элемента должны быть постоянными во всех экранах. Не вводим дополнительный яркий акцент без согласования.
3. Равнозначные элементы внутри одной группы имеют одинаковые размеры; высота пары учебных действий на главной одинакова при любом состоянии.
4. Не уменьшаем область касания ради компактности: минимальная интерактивная область — **44 × 44 CSS px**.
5. Не меняем учебную механику, сохранённые данные и поведение переходов при визуальной унификации.
6. Сохраняем особый простор учебной карточки: информационные карточки компактнее, учебные — свободнее.

| Роль | Токен / цвет | Применение |
|---|---|---|
| Фон приложения | `#FDF7ED` | Общая поверхность Paper |
| Карточка | `#FFFBF5` | Информационные/учебные блоки |
| Основной текст | `#0C1731` | Заголовки и важные значения |
| Вторичный текст | `#596676` | Обычные подписи |
| Важные пояснения | `#495463` | Контрастный текст инструкций |
| Основной синий | `#087BFA` | Новое обучение, главное действие, активные элементы |
| Тёмный синий | `#0046AA` | Нижняя точка синего градиента |
| Повторение | `#268137` | Зелёные обязательные действия |
| Жёлтый | `#ECB431` | Недельная цель, достижения |
| Успех: фон | `linear-gradient(#EDF9EC,#DFF2DD)` | Некликабельная карточка завершения |
| Успех: заголовок | `#174F29` | «Отлично! Всё повторено» |
| Успех: подпись | `#285D38` | 14 px, medium |
| Блокировка | `#EEE9E3` | Недоступные действия |

Смысл цветов: **синий — изучать/главное действие; насыщенный зелёный — повторить; светло-зелёный — завершено; жёлтый — цель; серый — неактивно/нейтрально**. Добровольное повторение сохраняет отдельное светло-голубое оформление, чтобы его не путали с обязательным.

Цвет — не единственный признак состояния: текст и доступность должны передавать тот же смысл.

## 3. Кнопки и состояния

| Семейство | Целевая высота | Особенности |
|---|---:|---|
| Главное учебное действие, главная | **78 px** | Радиус 21 px; две строки идентичной высоты |
| Информационная карточка «Всё повторено» | **78 px** | Та же высота; **не кнопка** |
| «Знаю / Не знаю», «Вспомнил / Не вспомнил» | **63 px** | Равные размеры в каждой паре |
| Кнопки нижней навигации | **49 px** | Короткий текст и иконка |
| Вспомогательные кнопки | **не менее 44 px** | Умеренный акцент, без лишнего объёма |
| Радиус крупных учебных кнопок | **21 px** | Другие элементы могут иметь меньший радиус |

78 px — **целевая согласованная высота**, а не текущая гарантированная высота всех существующих кнопок. При необычно длинном/увеличенном тексте приоритет — не обрезать содержание; эквивалентные кнопки растут вместе.

Состояния: обычное, нажатие, disabled, обязательное повторение, добровольная тренировка, завершено, фокус клавиатуры.

- «Учить новые слова»: яркий синий, стрелка справа, **без плюса**. Если недоступно — серый фон, замок и понятная причина внутри.
- Обязательное «Повторить сегодня»: насыщенный зелёный.
- Добровольное «Повторить ещё раз»: мягкий голубой.
- «Отлично! Всё повторено»: светло-зелёная **информационная карточка**, тёмно-зелёный жирный заголовок `#174F29`, подпись `#285D38` размером 14 px и средней насыщенности, анимированная галочка 350 мс.
- В паре «Знаю / Не знаю» выбор различается текстом и цветом; в паре «Вспомнил / Не вспомнил» — те же принципы.
- Неактивный элемент не уменьшает соседний и не анимируется при касании.
- Для клавиатуры нужен заметный `:focus-visible`; нативный `disabled` там, где действие действительно запрещено.

## 4. Иконки

**Целевой стиль:** один комплект функциональных SVG; скруглённые окончания и соединения; средняя толщина линии около **2–2,25 px** в 24-px исходной сетке.

| Использование | Размер |
|---|---:|
| Функциональная иконка в основной кнопке | 24 px |
| Вспомогательное действие | 20 px |
| Стрелка «Подробнее» | 16 px |
| Заголовок, навигация | 28–32 px |
| Компактный экран ≤375 CSS px: заголовок/навигация | 26–28 px |
| Галочка статуса | 28–32 px |

Сохраняем **фирменные цветные книгу и академическую шапочку**; не переводим их в чёрно-белый набор. Эмодзи допустимы для *тем словаря*, но не вместо функциональных иконок звука, поиска, назад, закрытия, выбора.

Область касания для кнопок-иконок — минимум 44 × 44 CSS px, включая компактные экраны; визуальный размер SVG и интерактивная область — разные параметры.

## 5. Карточки и интервалы

| Элемент | Целевой стандарт |
|---|---|
| Информационная карточка на главной | Радиус **21 px**, внутренний отступ **15–17 px** |
| Расстояние между соседними карточками/действиями | **11 px** |
| Учебная карточка | Более просторная, адаптивная; не ограничиваем механически 15 px |
| Поверхность | Тёплая светлая, тонкая граница, мягкая тень |
| Качество уровня | Две колонки «Занятия» и «Качество», инструкции под «Подробнее» |

Оставляем три кольца прогресса и текущую информационную архитектуру главной. Унификация не означает изменение состава карточек или их смысловых данных.

## 6. Типографика

| Элемент | Целевое значение |
|---|---|
| Основное английское слово на учебной карточке | **34 px** базово, адаптация при длинных словах |
| Перевод | **23 px** |
| Основной текст, примеры | **14–16 px** |
| Значимые пояснения | Обычно **не ниже 13–14 px** |
| Короткие вторичные подписи | **12–13 px** |
| Состояние «Всё повторено», подзаголовок | **14 px, medium**, `#285D38` |

Длинные слова должны переноситься либо масштабироваться без горизонтальной прокрутки; при увеличенном системном шрифте важнее читаемость, чем жёсткая высота.

## 7. Анимации

- Нажатие: `transform: scale(.975)`, **140 мс**, плавный возврат, без задержки выполнения действия.
- При нажатии допускается лёгкое затемнение; соседние элементы не смещаются.
- Анимации нет у `disabled`.
- Кольца на главной: **около 650 мс** при появлении; сохраняется возможность отключения.
- Галочка «Всё повторено»: **350 мс**.
- Раскрытие «Подробнее» сопровождается поворотом шеврона без лишней анимации страницы.
- Обязательно соблюдать `prefers-reduced-motion: reduce` — отключать необязательное движение.

## 8. Адаптивность и приёмка

Опорный компактный экран — **iPhone SE 2022, 375 × 667 CSS px** (типовой портретный viewport). Контроль дополнительно на больших iPhone и при увеличенном шрифте.

Проверять: (1) карточки и длинные слова не обрезаются; (2) все обязательные кнопки доступны; (3) клавиатура и нижние панели не перекрывают выбор; (4) парные кнопки равны по высоте; (5) текст «Всё повторено» читается; (6) анимации отключаются в reduced-motion; (7) фокус и 44-px зоны касания сохранены.

## 9. Управление изменениями

- Это **утверждённый целевой стандарт**. Отличия текущего интерфейса не устраняются автоматически.
- Любое изменение визуальных базовых компонентов сначала сравнивается с UI Kit; затрагивающие учебный поток изменения отдельно согласовываются.
- Не вводим новый цвет, радиус, стиль иконки или тип кнопки без явной причины.
- Реализация — небольшими PR по экранам, с проверкой данных/логики и мобильной приёмкой.
- Перечень несоответствий, приоритетов и ссылок на код: [UI_AUDIT.md](./UI_AUDIT.md).

## 10. Утверждённое поведение ручного подбора (6 ноября 2026)

- **Одна вертикальная прокрутка** внутри основного содержимого экрана: шапка, вкладки, темы и полный список слов прокручиваются вместе. Внутренние независимые прокрутки тем и списка слов запрещены.
- В обычном состоянии темы показаны **одним рядом из трёх карточек**. Выбранная тема находится первой; остальные темы доступны через «Все темы».
- «Все темы» разворачивает **полную сетку** вертикально, сдвигая список слов вниз; у сетки нет отдельной полосы прокрутки. При выборе тема становится активной, сетка автоматически сворачивается, а страница возвращается к началу списка слов.
- Снизу всегда закреплена **компактная панель** со счётчиком выбранных слов, кнопкой «Посмотреть» и основным действием «Начать изучение». Раскрытый список выбранных слов ограничивается по высоте, чтобы не перекрывать всю страницу.
- Пока выбрано меньше трёх слов, выводится краткое пояснение «Выбери минимум 3 слова». Максимум зависит от уровня (E.levelLimit(profile)), а не зашивается как 10.
- При переключении тем/поиска выбранные слова не теряются. Поиск работает по всему словарю. При появлении мобильной клавиатуры закреплённое действие не должно попадать под неё.
- На **iPhone SE 2022 (375×667)** список слов должен получать максимально возможную высоту без дополнительных раскрытий, кроме добровольного раскрытия тем или выбранных слов. Обязательно проверить длинную общую прокрутку и видимость нижней панели.

Согласованный экран запоминания: иллюстрация и текст ассоциации показываются постоянно, кнопки «Представить без картинки» нет; режим проверки знаний с собственными подсказками остаётся отдельным экраном.

## 11. Утверждённые иконки и панель выбранных слов (6 ноября 2026)

- Каждая из **22 тем** в `topics.js` получает отдельную встроенную SVG-иконку без эмодзи или универсального значка. Стиль единый: контур 2 px, `viewBox="0 0 24 24"`, визуальный размер **28×28 CSS px**, скруглённые линии.
- Цвет обычных иконок — `#284D79`, активной темы — `#087BFA`. Иконки не помещаем в дополнительные круги; подсветка активной карточки остаётся светло-голубой.
- Кнопка «Посмотреть» в закреплённой панели ручного подбора открывает **отдельную нижнюю шторку** высотой около **80% доступного viewport**, а не трёхстрочный список внутри панели.
- Шторка показывает все выбранные слова с переводами, поддерживает вертикальную прокрутку внутри списка и поштучное удаление. Заголовок, крестик закрытия и кнопка «Готово» остаются видимыми при прокрутке.
- Под шторкой основной список слов остаётся на прежнем месте. При закрытии пользователь возвращается к тому же месту; выбор слов не сбрасывается. При удалении последнего слова шторка закрывается автоматически.
- Шторка имеет доступную роль диалога, клавишу Escape и ограничение клавиатурного фокуса. На iPhone SE **375×667 CSS px** высота списка и элементы закрытия проверяются отдельно.
- Общая прокрутка экрана тем/слов из раздела 10 остаётся без изменений. Панель запуска занятия под шторкой сохраняет компактность.
