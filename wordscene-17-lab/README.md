# WordScene 17.0

Автономное PWA-приложение для изучения английских слов одним ребёнком на одном устройстве.

[Открыть WordScene 17](https://g-spitfire.github.io/tracker/wordscene-17-lab/)

- Все учебные данные сохраняются только локально. Firebase, регистрация, синхронизация и несколько аккаунтов не используются.
- В разделе «Профиль» только имя и возраст.
- При бездействии 30 минут незавершённое занятие отменяется; завершённый прогресс остаётся.
- Словарь, темы, иллюстрации и иконки PWA находятся внутри `wordscene-17-lab/`, зависимости от каталога WordScene 16.17 отсутствуют.
- Механика повторений, уровни и утверждённый Paper-дизайн описаны в [SPEC.md](SPEC.md).

Запуск: статический сервер из корня репозитория, открыть `/wordscene-17-lab/`. Проверки: `node --test wordscene-17-lab/*.test.cjs`.

До приёмки на iPhone и слияния веток текущий опубликованный вариант может отличаться от описанной здесь новой редакции.
