# WordScene 17.0 · лаборатория

[Открыть лабораторию на GitHub Pages](https://g-spitfire.github.io/tracker/wordscene-17-lab/)

На Paper-главной видны уровень ученика, доля изученных и закреплённых слов, очередь на сегодня и добровольное повторение оставшихся ошибок. Учебный прогресс хранится в отдельных локальных профилях WordScene 17. При возвращении до истечения 30 минут открывается та же карточка.

Запускайте статический сервер из корня репозитория и открывайте `/wordscene-17-lab/`. Для автоматических проверок из корня запустите `node --test wordscene-17-lab/*.test.cjs`. Облачный интерфейс доступен на loopback и подключается к локальным эмуляторам проекта `demo-wordscene17`.
