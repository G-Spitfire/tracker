# WordScene 17.0

Автономное PWA-приложение для изучения английских слов одним ребёнком на одном устройстве.

[Открыть WordScene 17](https://g-spitfire.github.io/tracker/wordscene-17-lab/)

- Все учебные данные сохраняются только локально. Firebase, регистрация, синхронизация и несколько аккаунтов не используются.
- В разделе «Профиль» только имя и возраст.
- При бездействии 30 минут незавершённое занятие отменяется; завершённый прогресс остаётся.
- Словарь, темы, иллюстрации и иконки PWA находятся внутри `wordscene-17-lab/`, зависимости от каталога WordScene 16.17 отсутствуют.
- Механика повторений, уровни и утверждённый Paper-дизайн описаны в [SPEC.md](SPEC.md).
- Сведения о происхождении словарных материалов и графики: [ATTRIBUTION.md](ATTRIBUTION.md).

Запуск: статический сервер из корня репозитория, открыть `/wordscene-17-lab/`. Проверки: `node --test wordscene-17-lab/*.test.cjs`.

WordScene 17 принята для повседневного использования и опубликована из `main`. Каталог `wordscene-17-lab/` сохраняет адрес, несмотря на историческое имя.

WordScene 16.17 выведена из эксплуатации: каталог `wordscene/` удалён из актуальной версии, исходники доступны в истории Git (до уборки: `77c150a`). Старый адрес больше не обслуживается. Прогресс 16.17 не переносится в 17.0 и не удаляется. Не очищайте данные Safari/localStorage и не удаляйте старые установки ради этой уборки.

Актуальная спецификация — только [SPEC.md](SPEC.md). Проверки браузеров и офлайн-режима: `node wordscene-17-lab/browser-acceptance.cjs` при установленном Playwright; `WS17_TEST_ORIGIN=https://g-spitfire.github.io/tracker` проверяет опубликованную версию. Физический iPhone автоматическими проверками не покрыт.
