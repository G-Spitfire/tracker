# Leveli — актуальный статус и оставшиеся задачи

Обновлено 7 ноября 2026 года после выпуска [PR №84](https://github.com/G-Spitfire/tracker/pull/84) и обновления документации в [PR №85](https://github.com/G-Spitfire/tracker/pull/85).

## Реализовано

- [x] Главная школьной успеваемости с двумя круговыми диаграммами, динамикой среднего, ориентирами и списком предметов.
- [x] Экран предмета: прогноз, взвешенные оценки, история, графики и сценарная цель.
- [x] Динамика: 0–1 оценка — без тренда; 2–5 — последняя относительно взвешенного среднего предыдущих; 6+ — последние три относительно предыдущих трёх. Пороги ±0,50 по неокруглённой разнице, доступно пояснение.
- [x] «Молодец» / «Подтянуть»: по три предмета, согласованные критерии и сортировки, корректные пустые состояния.
- [x] Пять акцентов; временно активна только тёмная тема (выбор светлой и системной скрыт, сохранённые предпочтения не удалены).
- [x] Единый комплект классических линейных иконок для действий. Устаревший выбор набора игнорируется, остальные настройки профиля сохраняются.
- [x] Точечная доводка интерфейса: компактная динамика, пустые ориентиры с учётом итогов, одна карточка официального итога, подпись сравнения со вчерашним средним и спокойнее оформленные карточки и графики.
- [x] Два опубликованных 3D-портрета Полины и Матвея, выбор другого персонажа и загрузка своей картинки.
- [x] Персонализация хранится **только на текущем устройстве**, изолированно по UID; облачная синхронизация этих настроек **не планируется**.
- [x] Офлайн-ресурсы PWA, резервный SVG-аватар и кэш школьных данных.
- [x] PR №84 объединён в `main`, опубликован на GitHub Pages.

## Проверки

- [x] Для PR №84: 18 модульных тестов успешно.
- [x] Для PR №84: браузерные сценарии на синтетических данных в Chromium и WebKit на Mac, в том числе два профиля, загрузка пользовательской картинки и восстановление настроек после перезапуска.
- [x] Для текущих правок: браузерные сценарии на синтетических данных для ширины 390 и 1280 px, включая старые профили, завершённые периоды, малые изменения и подпись сравнения со вчерашним средним.
- [x] Эмуляция экранов шириной 320, 360, 390 и 430 px.
- [x] Пользователь посмотрел опубликованную версию на iPhone; серьёзных проблем не обнаружил.
- [ ] Формальная проверка доступности с VoiceOver и тщательная визуальная приёмка всех сочетаний на физическом iPhone — по необходимости. Успешный WebKit-тест на Mac не равнозначен проверке на реальном устройстве.

## Техническая задолженность

- [ ] Дальнейшая консолидация исторического CSS-каскада только отдельными небольшими изменениями после визуального сравнения. Сведения о ранее выполненном аудите сохранены в `CSS_ICON_AUDIT_2026-11-06.md`.
- [ ] При изменениях школьной интеграции отдельно проверять реальный Firebase и работу внешнего Mac-синхронизатора; успешные браузерные тесты с заглушками не подтверждают доступность школьного сервиса.

## Границы работ

Нельзя менять формулы оценок, реальные данные детей, правила Firestore и авторизацию ради косметических правок. Другие проекты репозитория `tracker` не входят в область Leveli.

Текущее оформление описано в [дизайн-системе](DESIGN_SYSTEM.md). История решений и аудиторские снимки хранятся в [функциональном](FUNCTIONAL_AUDIT.md) и [техническом](IMPLEMENTATION_AUDIT.md) аудитах.
