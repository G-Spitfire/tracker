# Проверка технического ядра Левели на Mac

Тест только из ветки `leveli-core`. **Не публиковать в main.** Не пересылать пароль или данные ребёнка.

## Запуск
Открой Terminal на Mac и выполни:

```bash
git clone --branch leveli-core --single-branch https://github.com/G-Spitfire/tracker.git leveli-test
cd leveli-test/leveli
python3 -m http.server 8765 --bind 127.0.0.1
```

Открой в браузере на **этом же Mac**: http://localhost:8765/diagnostic.html

Если папка `leveli-test` уже существует, не запускай повторный `git clone`; обнови ветку внутри папки либо используй другую папку.

## Тест
1. Дождись «Нет активной сессии». Если ошибка, сохрани только текст ошибки.
2. Введи email и пароль **существующего** аккаунта ребёнка непосредственно в локальном браузере.
3. Нажми «Войти», затем «Проверить школьные данные».
4. Ожидаемый результат: «Документ найден. Поля верхнего уровня: …»; содержание оценок и UID экран не показывает.
5. Нажми «Выйти». Повтори для второго ребёнка.

## Возможные ограничения
- Firebase Auth может отклонить `localhost` как неразрешённый домен (`auth/unauthorized-domain`). Тогда **не меняй настройки самостоятельно**: сообщи код ошибки и согласуем безопасный способ теста.
- Этот тест **не доказывает** корректность Firestore Rules или структуры оценок; проверяется лишь вход и чтение своего документа.
- Тестовая страница использует существующий Firebase-проект, а не эмулятор. Она не записывает школьные оценки.
- Не размещай данные аккаунтов, скриншоты оценок или экспорт Firestore в репозитории.
- Для остановки сервера нажми Ctrl+C в Terminal.
