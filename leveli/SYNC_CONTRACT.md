# Левели — контракт достоверности синхронизации (проект)

**Область:** только самостоятельное приложение «Левели». Этот документ не означает, что Mac-загрузчик уже изменён.

## Уже действующий формат

Два документа `schoolGrades/{uid}`, содержащие `schemaVersion:1`, `source:"petersburgedu"`, `grades:[…]`. Обязательные поля и массив оценок не менять; обе записи учеников независимы.

## Предлагаемое необязательное поле `sync`

```json
{
  "sync": {
    "lastDiarySuccessAt": "2026-11-05T17:08:27+03:00",
    "lastFirebaseUploadAt": "2026-11-05T17:08:30+03:00",
    "failedRetryCount": 0
  }
}
```

- `lastDiarySuccessAt`: ISO-8601 timestamp **последнего успешного получения данных от электронного дневника**, а не времени чтения Firebase телефоном. Не обновлять при ошибке получения или неудачной авторизации дневника.
- `lastFirebaseUploadAt`: время реального подтверждения успешной загрузки в Firebase (если известно); приложение пока его не отображает.
- `failedRetryCount`: число **неудачных повторных попыток**, не первоначальных ошибок. Первая штатная ошибка оставляет значение 0; неудача первой повторной попытки через 30 минут устанавливает 1 (красный индикатор). Успех сбрасывает в 0.
- При первой ошибке не заменять имеющиеся оценки пустыми или частично собранными данными, не менять `lastDiarySuccessAt`. При ошибке записи в Firebase не выдавать её за успех.
- Не записывать ошибки с личными данными, cookie, токенами и паролями в Firestore.
- При отсутствии или ошибке поля `sync` приложение выводит «Когда проверялся дневник — неизвестно», не подменяя дату временем просмотра сайта.
- Ранее согласованный цикл: штатные запуски 07:00/14:00/19:00, повтор каждые 30 минут после ошибки до успеха или следующего штатного запуска. Не добавлять `StartInterval=1800` в тот же агент без проверки: это запускало бы и успешную синхронизацию каждые 30 минут.
- `lastDiarySuccessAt` должен фиксироваться для **полного успешного цикла обоих детей**; если будут независимые частичные успехи, контракт потребуется расширить до статуса по каждому ребёнку.

## Ограничение текущего этапа

В GitHub нет действующего локального Mac-скрипта `~/Library/Application Support/SpbSchoolGradesProbe/sync_then_upload.py`, поэтому изменение записи метаданных, повторов и persistency `launchd` **не реализовано**. Перед правкой на Mac нужно изучить локальный скрипт и plist, не выводя в чат учётные данные или школьные оценки.

## Проверка

Синтетические браузерные сценарии проверяют: есть валидная дата; метаданные отсутствуют; сбой первой повторной попытки; переключение профиля; офлайн сохранённые оценки. Реальная выгрузка проверяется отдельно.
