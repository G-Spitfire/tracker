# Левели — приложение для детей

Статус: разработка и локальная проверка в ветке `leveli-core`. Не считать опубликованным в `main` без отдельной проверки.

## Реализовано

- Firebase Authentication: вход и выход ребёнка.
- Школа: чтение оценок из `schoolGrades/{uid}`, группировка по предметам, текущие средние и отдельные итоговые оценки.
- Профиль: чтение имени из `profiles/{uid}`, приветствие на главной и имя во вкладке «Профиль».
- Навигация: главная, школа, обучение, профиль; отдельная страница наград. WordScene пока открывается как отдельное приложение; синхронизация его прогресса не подключена.

## Данные и права

Firebase project: `family-school-grades`. Коллекции:
- `schoolGrades/{uid}`: школьные оценки ребёнка, загружаемые отдельным механизмом синхронизации.
- `profiles/{uid}`: профиль ребёнка; сейчас используется строковое поле `name`, в коде предусмотрено необязательное `theme`.

В проверенных правилах Firestore для обеих коллекций клиенту разрешён только `get` собственного документа при `request.auth.uid == uid`. `list/create/update/delete` запрещены. Профили вручную созданы через Firebase Console; не хранить UID, пароли или реальные оценки в репозитории.

### Разобранная проблема

Имя не появлялось при сохранённой работоспособности оценок. При проверке выяснилось, что локальная копия отставала от ветки и не содержала `leveli/core/profile.js`. После `git pull origin leveli-core` файл появился. Повторные запросы к файлу давали 404 из-за невидимого символа в URL (в журнале: `/core/profile.js%E2%81%A0`), а не из-за отсутствия файла. После обновления страницы приложения пользователь подтвердил успешное отображение.

## Локальный запуск на Mac

```bash
cd ~/leveli-test
git pull origin leveli-core
cd leveli
python3 -m http.server 8766 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8766/index.html?v=7`. При повторной проверке можно изменить параметр `v` для обхода кэша. Терминал с сервером должен оставаться открытым. Если файл возвращает 404, проверить путь, фактическую папку сервера и отсутствие посторонних символов в адресе.
