# Левели

Самостоятельное мобильное приложение: `leveli/index.html`. Сборка не требуется.

## Школьная версия

- Главная выбранной четверти: две круговые диаграммы — прогноз/официальный итог по предметам (в центре средний предметных средних) и распределение обычных оценок (в центре количество оценок); нулевые категории скрыты, короткие легенды с единицами измерения под кругами. Светящийся накопительный график содержит текущий средний балл внутри, при наличии вчерашнего локального снимка показывает изменение день к дню. Далее — две колонки ориентиров и кликабельные предметы.
- Нажатие на сектор диаграммы фильтрует список предметов, на предмет — открывает оценки и динамику. Выбор другой четверти находится в настройках. Имя в приветствии выводится только из документа профиля Firebase. Нижнего меню нет.
- WordScene, награды, новости и настройки видимости карточек удалены из интерфейса. Ранее сохранённые данные пользователей не удаляются.
- Школа читает `schoolGrades/{auth.uid}` через Firebase; личные пароли дневника приложение не хранит.
- Прогноз доступен с трёх текущих оценок; официальный четвертной итог имеет приоритет. Средние учитывают официальные веса, если они переданы.
- Ориентиры «Молодец» и «Подтянуть» всегда показывают максимум три предмета без раскрытия; у каждого средний и динамика, без повторения прогноза. Строка предмета показывает название, число оценок мелким шрифтом, средний, крупный прогноз или официальный итог в рамке, компактную динамику. Динамика при 2–5 оценках = последняя минус взвешенное среднее предыдущих, при 6+ = взвешенное среднее последних трёх минус предшествующих трёх; пороги ±0,50.
- В деталях предмета есть сценарная цель по будущим пятёркам (вес 1), график с переключением среднего и отдельных оценок, история с фильтром «Контрольные» и раскрытием 10+10; официальный итог показан отдельно.
- Сохранённая копия показывается сразу, чтение Firebase автоматически повторяется при ошибке. Время чтения Firebase не выдаётся за синхронизацию дневника; если дата последней синхронизации не передана, это указано явно.
- Прежний IndexedDB `leveli-school-cache` остаётся для офлайн-чтения.

## Синхронизация оценок на Mac и VPN

- macOS `launchd` использует `~/Library/LaunchAgents/local.family.spb-grade-sync.plist`; настроено **три плановых запуска ежедневно по локальному времени Mac: 07:00, 14:00 и 19:00**. Скрипт: `~/Library/Application Support/SpbSchoolGradesProbe/sync_then_upload.py`.
- **Подтверждено пользователем:** при **включённом VPN** школьный сайт недоступен с этого Mac, поэтому синхронизация **Mac → школьный дневник → Firebase не проходит**. Успешное обновление возможно только когда VPN отключён и школьный сайт доступен. Ошибку доступа при включённом VPN не следует автоматически трактовать как ошибку алгоритма Leveli.
- В диагностике `launchctl print gui/$(id -u)/local.family.spb-grade-sync` зафиксированы `runs = 3`, `last exit code = 1`: это подтверждает неуспешное завершение последнего запуска, но само по себе не устанавливает причину для каждой попытки. Пользователь связывает сбой именно с активным VPN.
- Согласованное правило повторов при ошибке — раз в 30 минут до успеха или следующего планового запуска; **реализация этих повторов внутри скрипта пока отдельно не проверена**. Не считать наличие этого требования доказательством работающих повторов.
- Чтение данных из Firebase в приложении Leveli отдельно от выгрузки дневника на Mac. При выключенном VPN очередное получение оценок скриптом должно успешно завершиться, после чего Leveli сможет показать обновлённые данные.

## Проверка

Из корня репозитория:

```sh
node --test leveli/tests/*.test.cjs
python3 -m http.server 8765 --bind 127.0.0.1
```

Браузерная проверка: `node leveli/tests/browser.cjs` при доступном Playwright. `BROWSER_BINARY` задаёт путь Chromium, `TEST_BASE_URL` — адрес локального сервера. Используются только искусственные аккаунты и перехваченный транспорт Firebase. Проверка настоящего SDK не выполняет вход и запись в рабочие данные.

Публикация GitHub Pages происходит из `main`. Изменения публикуются только по согласованной задаче.

## Эталонный аватар — рабочая итерация 6 ноября 2026

Старые 10 встроенных аватаров, WebP-атлас, cutouts и технический черновик их экспорта удалены по запросу. Сейчас в галерее один **новый SVG-прототип** девочки с фиолетовым худи и наушниками. Карточка профиля горизонтальная: аватар слева, имя и действия справа, выступание приблизительно 5–10% над верхней границей карточки. Это проверка механики, а не финальное 3D-изображение. Поддержка личного загруженного изображения и UID-изолированные настройки не удалялись. Старые выбранные номера встроенных аватаров автоматически отображают текущий единственный прототип; исходные пользовательские сохранения не очищаются.
