# Левели

Самостоятельное мобильное приложение: `leveli/index.html`. Сборка не требуется.

## Разделы и данные

- Основная навигация: Главная / Школа / Обучение. Профиль и настройки открываются с главной, футбол — из карточки.
- Школа читает `schoolGrades/{auth.uid}` из существующего Firebase-проекта, схема 1, источник `petersburgedu`. Firebase служит транспортом уже полученных данных электронного дневника; приложение не хранит пароль дневника и не обращается к нему напрямую.
- Числовые текущие оценки отделены от посещаемости и официальных итогов. «Итоговая контрольная работа» является текущей работой. Среднее — арифметическое текущих оценок выбранной четверти.
- Прогноз: ниже 2,60 → 2; от 2,60 → 3; от 3,60 → 4; от 4,60 → 5. Расчёт использует исходное среднее без предварительного округления. Официальный итог имеет приоритет над прогнозом, среднее остаётся видно. Годовые оценки показаны отдельно.
- Предупреждение: среднее последних трёх датированных оценок по предмету ниже среднего выбранной четверти на 0,50 или больше. Если датированных оценок меньше трёх, предупреждения нет.
- Сохранённые оценки находятся в прежнем IndexedDB `leveli-school-cache`, отдельно для каждого UID. Выход очищает экран, но не историю. Повторное открытие офлайн доступно после успешной онлайн-загрузки и установки кэша приложения.
- Тема и видимость карточек сохраняются в `leveli-preferences-v1:{UID}`, гостевые настройки — отдельно. Ошибки хранилища не блокируют навигацию.
- Обучение читает только локальный профиль текущего UID и его облачную копию WordScene. Чужой или неопределённый гостевой прогресс не показывается как прогресс ребёнка. Для WordScene используется его отдельный вход.
- Футбольный модуль: контракт данных и локальный запуск описаны в [football/README.md](football/README.md). Нет прямых клиентских запросов к поставщику футбольных данных.

## Резервирование WordScene

WordScene хранит прогресс локально под ключом `word-scenes-v5` и автоматически создаёт облачные копии после входа в аккаунт. Гостевой прогресс отделён от аккаунтов; облачная версия не заменяет локальную без подтверждения. Правила восстановления описаны в [WordScene](../wordscene/README.md#сохранение-прогресса), проверка Firebase — в [FIREBASE-VALIDATION.md](FIREBASE-VALIDATION.md).

## Проверка

Из корня репозитория:

```sh
node --test leveli/tests/*.test.cjs leveli/football/tests/test_ui_data.mjs
python3 -m unittest discover -s leveli/football/tests
python3 -m http.server 8765 --bind 127.0.0.1
```

Браузерная проверка: `node leveli/tests/browser.cjs` при доступном Playwright. `BROWSER_BINARY` задаёт путь Chromium, `TEST_BASE_URL` — адрес локального сервера. Используются только искусственные аккаунты и перехваченный транспорт Firebase. Проверка настоящего SDK не выполняет вход и запись в рабочие данные.

Публикация GitHub Pages происходит из `main`. Изменения публикуются только по согласованной задаче.
