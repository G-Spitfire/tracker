# Левели

Самостоятельное мобильное приложение: `leveli/index.html`. Сборка не требуется.

## Запуск и восстановление сессии

- До первого ответа Firebase Auth приложение показывает краткую заставку с действующим фирменным знаком `brand/mark.svg`, названием Leveli и индикатором загрузки. Это устраняет кратковременное появление формы логина при восстановлении сохранённой сессии.
- После определения состояния авторизации заставка сразу исчезает: действующая сессия открывает приложение, а форма входа появляется только для гостя. Искусственной задержки нет. Сохранение сессии Firebase, учётные данные и правила чтения школьных оценок не изменены.

## Недельные сторис

- В «Итоги → Недели» выпуски сгруппированы по учебному году и четверти. В понедельник становится доступен выпуск за завершённую неделю (понедельник–воскресенье), если за неё есть текущие оценки с датами. Если неделя затрагивает две четверти, оценки каждой части учитываются отдельно.
- Пять экранов: «Твоя неделя в цифрах», «Сколько пятёрок?» (при росте — «Больше пятёрок!»), «Как меняется средний балл?», «Что изменилось по предметам?», «Главное за неделю». Они показывают количество оценок, пятёрки, накопительный средний, до трёх предметов с оценками за неделю и адаптивный итог. На экранах сравнения указаны даты обеих недель. Сравнение ведётся с предыдущей непустой неделей той же четверти. Первая непустая неделя показывает собственные результаты. Общий средний считается как на главной: взвешенные средние предметов усредняются с равным вкладом каждого предмета.
- После успешного чтения оценок при входе открывается только самый свежий выпуск, если он ещё не завершён. Прерванный просмотр продолжается с сохранённого экрана. Кнопка «Закрыть» на пятом, итоговом экране отмечает выпуск просмотренным. Прогресс хранится в этом браузере отдельно для каждого аккаунта. Исправления оценок обновляют архив и сравнения, сохраняя прогресс.

## Навигация и домашние задания

- Нижнее меню: «Главная», «Оценки», «Домашка», «Итоги». «Оценки» — прежняя вкладка «Предметы»; внутренние разделы и расчёты не изменены.
- «Домашка» пока является экраном-заготовкой с явным сообщением об отсутствии интеграции. Данные из единого сборщика пока не загружаются на этот экран. Это не состояние «заданий нет».

## Школьная версия

- Главная выбранной четверти: две круговые диаграммы — прогноз/официальный итог по предметам (в центре средний предметных средних) и распределение обычных оценок (в центре количество оценок); нулевые категории скрыты, компактные легенды с полными подписями и более плотными строками при четырёх и более категориях. Накопительный график содержит текущий общий средний балл. Подпись «Ко вчерашнему среднему» показывает разницу с последним локальным снимком за вчера, если он есть. Далее — две колонки ориентиров. Полный список предметов вынесен в отдельную вкладку «Предметы».
- Сектора и легенды обеих круговых диаграмм информационные, без нажатий, фильтров и переходов; вкладка «Предметы» содержит три внутренних раздела «Оценки», «Прогноз», «Итоги»; строки в «Оценках» и «Прогнозе» раскрываются на месте, без перехода в прежнюю подробную карточку. Закреплённое нижнее меню: «Главная», «Оценки», «Домашка», «Итоги». Во вкладке «Итоги» переключатель «Недели / Четверти»: «Недели» показывают архив выпусков текущего ученика; «Четверти» показывают только официальные четвертные оценки из данных текущего ученика за завершённые периоды (без прогнозов, контрольных и неподтверждённых итоговых работ). Если официальных оценок нет, показывается пояснение. Настройки открываются с главной через верхнюю кнопку; выбранная четверть действует на обеих вкладках. Навигация учитывает историю браузера. Имя в приветствии выводится только из документа профиля Firebase.
- WordScene, награды, новости и настройки видимости карточек удалены из интерфейса. Ранее сохранённые данные пользователей не удаляются.
- Школа читает `schoolGrades/{auth.uid}` через Firebase; личные пароли дневника приложение не хранит.
- Прогноз доступен с трёх текущих оценок; пороги: 4,60 → 5, 3,60 → 4, 2,60 → 3, ниже → 2. Официальный четвертной итог имеет приоритет и не включается в среднее текущих оценок. Средние учитывают официальные веса, если они переданы, для оценок без указанного веса расчётный вес равен 1.
- Ориентиры «Молодец» и «Подтянуть» всегда показывают максимум три предмета без раскрытия; у каждого средний и динамика, без повторения прогноза. Строка предмета показывает название, число оценок мелким шрифтом, до трёх последних текущих оценок (оценки за сегодня и вчера выделены рамкой), средний, крупный прогноз или официальный итог в рамке, компактную динамику. В этой колонке двойка красная, тройка янтарная, независимо от акцента и динамики. Динамика при 2–5 оценках = последняя минус взвешенное среднее предыдущих, при 6+ = взвешенное среднее последних трёх минус предшествующих трёх; пороги ±0,50.
- Прежняя отдельная подробная карточка предмета больше не используется в текущей навигации. Её график, сценарная цель и расширенная история не представлены как отдельный экран; актуальные оценки, средний балл, динамика, прогноз и официальные итоги доступны во внутренних вкладках «Предметы».
- Сохранённая копия показывается сразу, чтение Firebase автоматически повторяется при ошибке. Время чтения Firebase не выдаётся за синхронизацию дневника; если дата последней синхронизации не передана, это указано явно.
- Прежний IndexedDB `leveli-school-cache` остаётся для офлайн-чтения.

## Синхронизация оценок на Mac и VPN

- Загрузчик Mac записывает в `schoolGrades/{uid}.syncedAt` время завершения полного сбора оценок обоих учеников. При сбое сбора выгрузка пропускается. Поля `lastSuccessfulSyncAt` и `lastSyncAt` поддерживаются для совместимости. Время чтения Firebase и время записи локального кэша для этой подписи не используются.
- Успешное чтение из Firebase даёт зелёную отметку для даты за последние 24 часа. При чтении из кэша известная дата остаётся с нейтральной отметкой. Если дата отсутствует, некорректна или опережает часы устройства более чем на пять минут, приложение показывает, что дата неизвестна (либо что оценки сохранены локально).
- macOS `launchd` использует `~/Library/LaunchAgents/local.family.spb-grade-sync.plist`; настроено **три плановых запуска ежедневно по локальному времени Mac: 07:00, 14:00 и 19:00**. Скрипт: `~/Library/Application Support/SpbSchoolGradesProbe/sync_then_upload.py`.
- **Подтверждено пользователем:** при **включённом VPN** школьный сайт недоступен с этого Mac, поэтому синхронизация **Mac → школьный дневник → Firebase не проходит**. Успешное обновление возможно только когда VPN отключён и школьный сайт доступен. Ошибку доступа при включённом VPN не следует автоматически трактовать как ошибку алгоритма Leveli.
- В диагностике `launchctl print gui/$(id -u)/local.family.spb-grade-sync` зафиксированы `runs = 3`, `last exit code = 1`: это подтверждает неуспешное завершение последнего запуска, но само по себе не устанавливает причину для каждой попытки. Пользователь связывает сбой именно с активным VPN.
- Согласованное правило повторов при ошибке — раз в 30 минут до успеха или следующего планового запуска; **реализация этих повторов внутри скрипта пока отдельно не проверена**. Не считать наличие этого требования доказательством работающих повторов.
- Чтение данных из Firebase в приложении Leveli отдельно от выгрузки дневника на Mac. При выключенном VPN очередное получение оценок скриптом должно успешно завершиться, после чего Leveli сможет показать обновлённые данные.

## Безопасность Firebase

Правила Firestore проекта `family-school-grades` были проверены на сервере 1 ноября 2026 года: пользователь может читать свои школьные данные, чтение чужих данных и клиентская запись школьных оценок и профиля запрещены. Проверки выполнялись с временными тестовыми аккаунтами и синтетическими данными; рабочие оценки детей не перезаписывались. Прежний набор правил сохранён на сервере для контролируемого отката; перед любыми последующими изменениями правил необходимо проверить актуальную серверную версию и исключить перезапись чужих правок. Это исторически подтверждённая проверка, а не гарантия неизменности текущих серверных правил.

## Проверка

Из корня репозитория:

```sh
node --test leveli/tests/*.test.cjs
python3 -m http.server 8765 --bind 127.0.0.1
```

Браузерная проверка: `node leveli/tests/browser.cjs` при доступном Playwright. `BROWSER_BINARY` задаёт путь Chromium, `TEST_BASE_URL` — адрес локального сервера. Используются только искусственные аккаунты и перехваченный транспорт Firebase. Проверка настоящего SDK не выполняет вход и запись в рабочие данные.

Публикация GitHub Pages происходит из `main`. Изменения публикуются только по согласованной задаче. PR №112 объединён с `main` 9 ноября 2026 года; пользователь подтвердил, что опубликованная версия работает. Автоматические проверки GitHub Actions прошли успешно, отдельная браузерная проверка мобильной вёрстки после PR №112 не проводилась.

## Персонализация

Настройки темы, акцента и аватара хранятся на этом устройстве отдельно для каждого UID. Сейчас принудительно используется тёмная тема; ранее сохранённое предпочтение темы не удаляется, но выбор темы скрыт. Доступны пять акцентов. Для действий используется единый комплект классических линейных значков. Старое поле `pack` игнорируется при чтении и выпадает из записи при следующем сохранении настроек того же аккаунта.

Полина и Матвей получают свой 3D-портрет автоматически. В настройках можно выбрать один из четырёх новых образов Полины или шести образов Матвея. Два прежних портрета и загрузка своей картинки остаются доступны. Новые прозрачные WebP загружаются по мере просмотра галереи и после загрузки доступны офлайн. Прежний локальный формат настроек и картинки сохранены. Новые изображения обрабатываются в браузере и хранятся локально. Пользователь осмотрел опубликованную версию на iPhone без существенных замечаний; формальный аудит доступности VoiceOver ещё не проводился.

## Действующие правила ориентиров и динамики

- 0–1 текущая оценка: динамика отсутствует; 2–5: последняя оценка минус взвешенное среднее предыдущих; 6+: взвешенное среднее последних трёх минус непосредственно предыдущих трёх. При равных датах — устойчивый порядок. Порог стрелок ±0,50 проверяется до округления.
- «Молодец» — прогноз 5 без падения ≤ −0,50. «Подтянуть» — прогноз 2–3 или падение ≤ −0,50 при прогнозе 4–5. Предметы с официальным четвертным итогом исключены.
- Максимум три предмета в группе без раскрытия; «Подтянуть» сортируется: прогноз 2, затем 3, затем ухудшающиеся 4–5, внутри по возрастанию среднего; «Молодец» — по убыванию среднего. Пустые колонки скрываются; если ориентиров нет, текст зависит от наличия официальных итогов и прогнозов по остальным предметам.
- Разница отображается с одним знаком. Ноль и значения, округляющиеся до нуля, показываются как `0,00`, малые изменения — числом без стрелки. Прочерк означает отсутствие расчёта. Пояснение по нажатию показывает оценки и веса. **Статус:** формула и пояснение реализованы; после PR №84 пройдены 18 модульных тестов и браузерная приёмка в Chromium/WebKit с синтетическими данными. Пользователь осмотрел опубликованный интерфейс на iPhone. Полная проверка VoiceOver на физическом устройстве отдельно не подтверждена.

## Документация и ресурсы

Согласованные аватары, PWA-иконки, `prototype-girl.svg` (резервный аватар) и ресурсы офлайн-кэша являются рабочими файлами, а не черновиками: не удалять их только из-за имени. Варианты светлой и монохромной графики в `brand/` сохранены как векторные исходники. 

Настройки персонализации намеренно **не синхронизируются между устройствами**; изменение этого решения требует отдельного согласования.


### Экран «Предметы» (текущий UX)

- Три вкладки для выбранной в настройках четверти: «Оценки», «Прогноз», «Итоги». Отдельного переключателя четверти здесь нет.
- «Оценки»: числовой индикатор динамики без подписи «динамика»; одна строка последних оценок без счётчика скрытых; раскрытие показывает все оценки в хронологическом порядке, от ранних к поздним. Нажатие на оценку показывает тип работы, дату и исходный вес, если он известен. Сегодняшние и вчерашние оценки выделены рамкой.
- «Прогноз»: средний балл, динамика и существующий расчёт прогноза; подпись «динамика» под числом убрана. Значение динамики показывается с одним знаком после запятой; пороги стрелок и алгоритмы расчётов не менялись.
- После PR №112 строки предметов адаптированы для узких экранов: уменьшены вертикальные отступы, расстояния между оценками и показателями, настроено компактное расположение названия, среднего, динамики и прогноза. Это изменение CSS, не формул или данных.
- «Итоги»: только официально выставленный итог за выбранную четверть, иначе «Итог ещё не выставлен».
- Цвета оценок: 5 — зелёный, 4 — жёлтый, 3 — оранжевый, 2 — красный. Отдельной легенды цветов нет.


### Экран «Итоги»: годовая таблица

Вкладка «Недели» сохраняет недельные истории. Вкладка «Четверти» показывает все предметы одной таблицей: I, II, III, IV четверти и год. В ячейках только официально выставленные оценки; отсутствие итога обозначается прочерком. Текущая четверть выделена в заголовке. Прогнозы в таблице не используются. Проверка на мобильных устройствах ещё требуется.
