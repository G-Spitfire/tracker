# Левели — техническое ядро (черновая ветка)

Только ES-модули, без сборки и без изменения существующего интерфейса.
- `firebase.js`: инициализация Firebase из конфигурации, которую предстоит сверить с действующим проектом.
- `auth.js`: вход существующего пользователя, выход, наблюдение за сессией.
- `school.js`: чтение только `schoolGrades/{uid}` текущей сессии. Записи нет.

**Важно:** модули ещё не подключены к `leveli/index.html`. Конфигурация Firebase, фактическая схема документа и работа Security Rules в этой ветке пока не проверены. Реальные данные и пароли в GitHub не размещать.

## Следующий этап
1. Получить и сверить публичную Firebase web-конфигурацию с действующим проектом.
2. Подключить модули к временному диагностическому экрану в этой же ветке.
3. Проверить вход, выход, чтение своего документа, отсутствие документа, сетевые ошибки и запрет чужого UID.
4. Только после проверки нормализовать реальные школьные оценки и подключать интерфейс.
