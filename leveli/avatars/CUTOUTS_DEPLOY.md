# Leveli — прозрачные аватары Б3

Статус: **10 новых иллюстраций опубликованы в ветке PR #75; ожидается объединение в main и проверка на iPhone**.

## Исходный дизайн
Пять иллюстраций Полины (9 лет) и пять Матвея (15 лет) по согласованному пользователем листу. Файлы нарезаны из одобренного изображения, подготовлены с прозрачностью, без изменения персонажей.

## Файлы
- `leveli/avatars/cutouts/avatar-01.webp` … `avatar-10.webp`, каждый 512×512 с прозрачностью.
- Встроенный исходный лист имел ограниченное разрешение, поэтому 512 px — размер холста, а не гарантия детализации 512 px.
- Оригинальные файлы PNG/WebP и галерея находятся в архиве Библиотеки ChatGPT `/Leveli/leveli_new_avatars_v3.zip`.
- Все десять WebP перечислены в precache service worker; кэш `leveli-v24-transparent-avatars`.

## Контракт отображения
- Сохраняются старые индексы выбора `avatar` 0–9 и значение `custom` в UID-изолированном localStorage.
- Отображение по индексам выбора: 0–4 — Полина, 5–9 — Матвей; любой ребёнок может выбрать любую иллюстрацию.
- В Б3 при удачной загрузке появляется крупный прозрачный силуэт с тенью и выходом за рамку; если файл не загрузился, остаётся старый WebP-атлас.
- Собственная фотография ребёнка работает как раньше, без эффекта прозрачной вырезки.

## Проверки
- CI должен проверить все десять HTTP-ресурсов, CSS-эффект, галерею и вход/выход.
- Перед окончательным утверждением проверить в Safari/iPhone обрезание волос/одежды, чёткость Retina, все темы и размер 320/390/430px.
- Не объявлять результат прошедшим приёмку на реальном iPhone без проверки пользователем.
