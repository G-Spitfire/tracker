# Моя капа 2.0

Локальное PWA для учёта дневного и ночного ношения ортодонтического трейнера.

## Запуск

Для корректной работы IndexedDB и PWA запустите локальный веб-сервер:

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`. Для установки на телефон опубликуйте **все файлы** на HTTPS-хостинге, например GitHub Pages. Открытие `index.html` напрямую через `file://` не поддерживается.

## Хранение и миграция

Данные хранятся в IndexedDB браузера и не синхронизируются между устройствами. В настройках доступны экспорт и восстановление JSON. При первом открытии на **том же origin**, где использовалась версия 1.0, приложение переносит `localStorage['moya-kapa-v1']` в IndexedDB; исходные данные остаются нетронутыми. При переносе старые ночные отметки сохраняют исходную дату и интерпретируются как дата начала ночи: при необходимости исправьте их в истории. Старый активный таймер переносится и требует проверки перед завершением.

## Тестирование

```bash
node --test tests/core.test.mjs
```

При обновлении service worker измените имя `CACHE` в `sw.js`, чтобы устройства получили новые файлы.

## Ограничения

Напоминаний и синхронизации нет. При удалении данных сайта история может пропасть. Приложение не заменяет рекомендации ортодонта. Продолжительные таймеры требуют подтверждения; неверные записи можно удалить и добавить корректное время вручную.
