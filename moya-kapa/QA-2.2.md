## Повторный запуск

```sh
node --test moya-kapa/tests/*.test.mjs wordscene/*.test.cjs
PW_MODULE=playwright SCREENSHOT_DIR=/absolute/path/to/screenshots node moya-kapa/tests/browser.cjs
```

Для второго запуска нужен установленный Playwright с браузером. При использовании системного Chromium задайте `CHROMIUM_PATH`. Тест поднимает временный локальный сервер сам.
