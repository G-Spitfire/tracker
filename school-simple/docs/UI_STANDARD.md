# Школа — Soft Minimal Compact
Действующий стандарт 1.33.32. Источник реализации: styles.css, index.html, assets/icons.js. История решений — Git и исторический DESIGN_SYSTEM.md.

## 1. Принципы
Mobile-first, компактность без потери читаемости. Нейтральные поверхности, акцент для значимых и выбранных элементов. Не вводить новые размеры без необходимости.

## 6. Компоненты
- Шапка прокручивается; четыре вкладки в фиксированной нижней навигации с safe area. Профиль отдельно.
- Главная: шесть одинаковых KPI 2×3, минимум 96 px (94 до 360), зазор 6, отступ до графика 4. Линия — накопительная история четверти, шкала от 2 (от 1 при меньшем значении), до пяти дат, градиент 18%→0, без пунктира. Легенда кольца компактная. Недельный тренд сравнивает сопоставимые предметы двух семидневных периодов.
- Оценки: фильтры в шапке вертикально, чекбоксы 16 px, подписи 12 (11 до 360), зона 22 px. Акцент и белая галочка. Фильтры независимы, совместно дают двойки за контрольные; средние и прогноз неизменны. Заголовки Предмет/Средний. Поля строки 4, отступ до оценок 2, перенос без горизонтальной прокрутки. Динамика 3 оценки 1+1, 4–5 2+2, от 6 3+3, иначе нейтрально; средний два знака, динамика один. Акцентная точка новой оценки независима от прочтения.
- Прогноз: Предмет/Средний/Прогноз, от худшего к лучшему, без разделителей, полосы 6 px.
- Расписание: независимые строки полной ширины, длинные темы переносятся, оценки семантические и открывают детали.
- Домашка: отступ предмет→текст 4, вертикальные поля 6; пустые состояния текстовые, без иллюстраций.
- Модальные окна: заголовок 16/600, текст 14, подписи 12, поля 16, промежутки 8, максимум 80% высоты; прокручивается тело, заголовок и кнопки остаются видимыми; окно поверх навигации.
- Что нового: только непрочитанные новые/исправленные оценки отдельно по ученикам; группировка по дате оценки, неизвестная дата явно. Акцентный счётчик 9+, строки без переходов. «Прочитал» очищает окно и счётчик, закрытие без подтверждения не меняет статус. Технический учёт сохраняется. Push отсутствует.
- Без троек и двоек: завершённые учебные дни четверти по расписанию и урокам, без сегодняшнего дня; день без оценок засчитывается, 2/3 прерывают серию.

## 7. Проверка
320/375/393/430 px, светлая/тёмная/системная темы, шесть акцентов, оба ученика, пустые и заполненные состояния, SVG, модальные окна, отсутствие наложений и переполнения. GitHub Actions обязательны; физический iPhone Safari/PWA проверяется отдельно. При изменении правила обновлять этот документ и тесты, не дописывать исторические противоречащие правила.
