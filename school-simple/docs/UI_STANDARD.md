# Школа — Soft Minimal Compact
Действующий стандарт 1.33.42. Источник реализации: styles.css, index.html, assets/icons.js. История решений — Git и исторический DESIGN_SYSTEM.md.

## 1. Принципы
Mobile-first, компактность без потери читаемости. Нейтральные поверхности, акцент для значимых и выбранных элементов. Не вводить новые размеры без необходимости.

## 6. Компоненты
- Шапка прокручивается; четыре вкладки в фиксированной нижней навигации с safe area. Профиль отдельно; выбор учебной четверти 1–4 в профиле, сегменты 32 px.
- Главная: шесть одинаковых KPI 2×3, минимум 90 px (88 до 360), зазор 6, отступ до графика 4. Линия — накопительная история четверти, шкала от 2 (от 1 при меньшем значении), до пяти дат ДД.ММ, градиент 18%→0, без пунктира. Легенда кольца компактная. Недельный тренд сравнивает сопоставимые предметы двух семидневных периодов.
- Оценки: фильтры КР/СР и Двойки в шапке горизонтально, смещение вниз 3 px, чекбоксы 16 px, подписи 12 (11 до 360), зона 32 px. Акцент и белая галочка. Фильтры независимы, совместно дают двойки за контрольные; средние и прогноз неизменны. Заголовки Предмет/Средний. Поля строки 2, отступ до оценок 0, перенос без горизонтальной прокрутки. Динамика 3 оценки 1+1, 4–5 2+2, от 6 3+3, иначе нейтрально; средний два знака, динамика один. Акцентная точка новой оценки независима от прочтения.
- Прогноз: Предмет/Средний/Прогноз, от худшего к лучшему, без разделителей, полосы 6 px.
- Расписание: независимые строки полной ширины, вертикальные поля 6 px, длинные темы переносятся, оценки семантические и открывают детали.
- Домашка: отступ предмет→текст 2, вертикальные поля 6; пустые состояния текстовые, без иллюстраций.
- Модальные окна: заголовок 16/600, текст 14, подписи 12, поля 16, промежутки 8, максимум 80% высоты; прокручивается тело, заголовок и кнопки остаются видимыми; окно поверх навигации.
- Что нового: только непрочитанные новые/исправленные оценки отдельно по ученикам; группировка по дате оценки, неизвестная дата явно. Акцентный счётчик 9+, строки без переходов. «Прочитал» очищает окно и счётчик, закрытие без подтверждения не меняет статус. Технический учёт сохраняется. Push отсутствует.
- Без троек и двоек: завершённые учебные дни четверти по расписанию и урокам, без сегодняшнего дня; день без оценок засчитывается, 2/3 прерывают серию.

## 7. Проверка
320/375/393/402 px, светлая/тёмная/системная темы, шесть акцентов, оба ученика, пустые и заполненные состояния, SVG, модальные окна, отсутствие наложений и переполнения. GitHub Actions обязательны; физический iPhone Safari/PWA проверяется отдельно. При изменении правила обновлять этот документ и тесты, не дописывать исторические противоречащие правила.

При запуске загружается снимок; при возвращении в приложение проверка выполняется после пяти минут с последней попытки, если нет открытого модального окна. Периодической сетевой проверки нет. Ручная синхронизация сохранена.

Исторические иллюстрации пустых состояний сохранены в каталоге, но исключены из загрузки и обязательного офлайн-кэша рабочей оболочки.

## Анимации (1.33.42)
Только семь согласованных эффектов: линия 450 мс и заливка; касание кнопок scale(.96) 100 мс; подложка переключателя и календаря 180 мс; модальное окно 200 мс, 8 px; колокольчик 500 мс только при новых событиях; числовые KPI 400 мс при изменении в том же контексте ученика и четверти. Без изменения геометрии, задержки навигации, анимации кольца, счётчика или экрана. Учитывать prefers-reduced-motion; неизменные данные не запускают эффекты повторно.

Настройка «Анимации» под акцентными цветами: переключатель включён по умолчанию, хранится локально для обоих учеников. Выключает семь эффектов, не индикаторы загрузки и синхронизации. Системное уменьшение движения имеет приоритет.

Повторный вход на главную с тем же графиком не запускает отрисовку; выбор линейного после кольцевого запускает. Подложки всех переключателей движутся независимо от смены ученика/четверти. Закрытие модального окна 150 мс. Неизменный HTML основного раздела сохраняется при повторном render; отклик касания применяется к визуальным дочерним элементам, а не зоне кнопки.

### Стабильная отрисовка и закреплённая шапка
Шапка sticky, без JS прокрутки; высота прежняя. Логотип и индикаторы сохраняют DOM-узлы при обновлении графика. Главная обновляет только изменившиеся блоки. Повторная отрисовка неизменных данных не прерывает числовую анимацию; колокольчик сохраняется при завершении синхронизации.

Проверять реальную геометрию шапки при прокрутке в Chromium и WebKit; физическая iOS PWA отдельно.
