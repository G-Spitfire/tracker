# Школа

**Текущая версия:** 1.33.59 Premium.
**Приложение:** https://g-spitfire.github.io/tracker/school-simple/  
**Основная ветка:** `main`  
**Источник данных:** электронный дневник Санкт-Петербурга — https://dnevnik2.petersburgedu.ru/

«Школа» — PWA для просмотра реальных оценок, расписания и домашних заданий двух учеников. Демонстрационные данные в рабочем приложении удалены. Сквозная проверка сбора, шифрования, публикации снимка и совпадения расшифрованных данных с локальным источником выполнена. Пользователь проверил открытие приложения на Mac и iPhone.

## Действующий интерфейс 1.33.59 Premium

- Верхняя панель прокручивается вместе с содержимым; нижняя навигация закреплена независимо, с учётом безопасной зоны iOS.
- Только новые и исправленные оценки создают уведомления, отдельно по ученикам; домашние задания не создают уведомлений. В окне показываются непрочитанные события по дате оценки; кнопка «Прочитал» очищает список, закрытие без подтверждения не меняет статус.
- Нормативный документ — [UI_STANDARD.md](docs/UI_STANDARD.md). Описания прежних релизов ниже сохранены как история и не являются действующими требованиями при расхождении с ним.

### Оформление и аналитика Premium
- Deep Black: фон #000000, KPI #171717, границы #292929. Apple Modern задаёт семантические цвета независимо от выбранного акцента. Полная палитра — в UI_STANDARD.md.
- Нейтральные KPI, тонкие внутренние границы и мягкие тени; число недельной динамики нейтральное; зелёная стрелка при росте > 0, красная при снижении ≤ −0,20, иначе нейтральная.
- Красная поверхность «Под риском»: более 30% предметов с оценками имеют средний ниже 3,60 либо хотя бы один средний ниже 2,60. Без оценок сигнал отсутствует.
- «Без двоек»: завершённые учебные дни по доступным урокам и расписанию в пределах учебного года, независимо от выбранной четверти; тройки не прерывают серию. История ограничена полнотой снимка дневника; уроки доступны за текущую четверть, поэтому серия может быть занижена. Последняя двойка учитывается даже без соответствующего урока. Сборщик и хранение не меняются. В декабре третья плитка заменяется «Лёгким инеем»; с 1 января возвращается доля пятёрок.
- Сегодняшняя дата в расписании обозначена контуром, выбранная — заливкой.
- Звуки и награды отложены. Геометрия не меняется.

## Динамика по предметам (с 1.33.11)

В разделе «Оценки» под средним каждого предмета показывается изменение после последней оценки выбранной четверти: сравнение средних двух последовательных групп: при 3 оценках — последняя 1 против предыдущей 1; при 4–5 — последние 2 против предыдущих 2; при 6 и более — последние 3 против предыдущих 3 (при совпадении даты — порядок в данных). При 1–2 оценках динамика не рассчитывается. Индикатор зелёный при росте, красный при снижении и нейтральный при недостатке данных либо изменении, округляющемся до 0,0. Изменение показывается с одним десятичным знаком, средний балл — с двумя. Это **не** семидневная динамика главной страницы. При фильтре «Только контрольные» средний и динамика по-прежнему считаются по всем оценкам четверти, а фильтр влияет только на показанные оценки.

## Данные и синхронизация

1. Локальный сборщик на Mac получает данные из электронного дневника.
2. Исходный JSON остаётся на Mac и не публикуется в репозитории.
3. `school-sync/publish.py` нормализует данные и шифрует снимок AES-256-GCM.
4. В отдельную ветку `school-data` отправляется только `data.enc.json`.
5. Браузерный клиент загружает снимок, запрашивает пароль шифрования при первом подключении, расшифровывает данные и сохраняет снимок и ключ CryptoKey в IndexedDB.
6. При открытии приложение сначала показывает ранее сохранённый снимок из IndexedDB, если он есть, и параллельно получает свежие данные. После успешного обновления экран перерисовывается автоматически. Если кэша ещё нет, показывается фирменная заставка загрузки; при ошибке без кэша доступна повторная попытка. При ошибке сети с кэшем приложение продолжает показывать сохранённые данные.

Пароль не хранится в исходном коде или репозитории. На Mac он хранится в Keychain. Ключ шифрования в браузере сохраняется как неэкспортируемый CryptoKey; пароль в открытом виде не сохраняется. Публично доступен только шифротекст, однако его конфиденциальность зависит от надёжного уникального пароля.

Текущая клиентская логика: при запуске и возвращении в приложение (если прошло не менее пяти минут с последней попытки, есть сеть и нет открытого окна) выполняется проверка снимка. Ручное обновление доступно; периодических фоновых сетевых запросов нет. Ошибка имеет приоритет над свежестью даже при наличии кеша. Снимок моложе 150 минут считается свежим, иначе — устаревшим; время сбора и время успешной сетевой проверки различаются. Запрос и чтение ответа ограничены 30 секундами. Закрытый диалог не открывается повторно по завершении запроса. Service Worker предпочитает сеть для оболочки и версии, при сетевом исключении использует кеш; снимок хранится отдельно в IndexedDB. Кеш оболочки версионирован; старые кеши School очищаются при активации. Проверка версии при запуске и возвращении в приложение инициирует не более одной попытки обновления на версию за сессию.

## Локальный сборщик на Mac (историческая справка, до Collector 2.0)

> Актуальные инструкции Collector 2.0 хранятся отдельно; команды ниже исторические.

Сборщик и его окружение находятся вне репозитория:

| Назначение | Путь |
|---|---|
| Сборщик | `~/Library/Application Support/SchoolDiary/collector.py` |
| Python / Playwright | `~/school-diary-venv/` |
| Профиль Chrome | `~/.school-diary-browser-profile/` |
| Исходный JSON | `~/school-diary-data.json` |
| LaunchAgent | `~/Library/LaunchAgents/local.school.diary.collector.plist` |
| Журнал | `~/Library/Logs/school-diary-collector.log` |
| Журнал ошибок | `~/Library/Logs/school-diary-collector-error.log` |

По ранее проверенной конфигурации LaunchAgent запускался в будние дни в 12:00, 14:00, 16:00, 18:00 и 20:00 по местному времени Mac; позднее согласовано добавить субботу, но текущую конфигурацию на Mac по одному репозиторию подтвердить нельзя. Ручной запуск сборщика и принудительный запуск задания LaunchAgent проверялись. Сам факт длительной стабильной работы всех временных запусков и автоматического восстановления после истечения авторизации требует наблюдения. Если Mac выключен или спит, своевременное выполнение не гарантируется.

Ручная проверка:

```bash
"$HOME/school-diary-venv/bin/python" "$HOME/Library/Application Support/SchoolDiary/collector.py" --non-interactive
tail -n 30 ~/Library/Logs/school-diary-collector.log
launchctl print gui/$(id -u)/local.school.diary.collector
```

Профиль Chrome и исходный JSON содержат персональные данные и/или авторизационную информацию. Не добавлять их в Git, не публиковать и не прикладывать к публичным задачам.

## Правила расчётов и ограничения

- Общий средний балл на главной рассчитывается как среднее арифметическое предметных средних, а не как среднее всех оценок подряд.
- Оценки распределяются по четвертям по заданным в коде календарным диапазонам учебного года 2026/2027. Это локальная календарная классификация, а не отдельное поле четверти из источника дневника.
- Прогноз четвертной оценки — предварительная эвристика с порогами 2,60 / 3,60 / 4,60. Это не официальный расчёт школы.
- Показатель «Под риском» использует средний балл предмета ниже 3,60 и также является ориентиром, а не официальным статусом.
- Динамика — разница средних по сопоставимым предметам за последние 7 календарных дней (включая сегодня) и предыдущие 7 дней, независимо от границы четверти. Каждый предмет имеет одинаковый вес; достаточно одного общего предмета. Без общих предметов отображается «—».
- Серия «Без двоек» определяется по уникальным доступным учебным датам до сегодняшней в диапазонах учебного года, после последней двойки; тройки и дни без оценок не прерывают её. Выбранная четверть не влияет; неполная история уроков ограничивает результат.
- Источник не предоставляет подтверждённую дату сдачи домашнего задания в используемом формате. Приложение оценивает срок по следующему запланированному уроку того же предмета. Эта дата может отличаться от официального срока.
- Динамика и серия дней покрыты автоматическими регрессионными тестами; пользователь подтвердил корректность динамики у обоих детей после выпуска 1.32.5.

## История: актуальность данных дневника 1.33.3 (уточнена в 1.33.52)

Индикатор на главной оценивает время формирования снимка Mac (`generatedAt`), а не время последней успешной загрузки GitHub. Зелёный — снимку менее 150 минут, оранжевый — 150 минут и более или дата снимка неизвестна; красный — нет пригодных данных. Во время запроса сохраняется состояние загрузки. Если сеть недоступна, но локальный снимок есть, он остаётся доступен, а причина ошибки видна в диалоге. Индикатор пересчитывается каждую минуту, пока приложение открыто.

В диалоге отдельно показываются «Данные собраны» (время `generatedAt`) и «GitHub проверен» (время успешной сетевой проверки). Успешное получение старого файла не означает свежесть школьных данных. Порог 150 минут согласован с двухчасовым расписанием Mac. Расписание LaunchAgent, публикация, IndexedDB и ручная проверка не изменены.

## Исторические правила событий (1.33.19; заменены)

При первом успешном сетевом снимке приложение создаёт локальную базу оценок и актуальных домашних заданий, без уведомлений о старых записях. На последующих сетевых обновлениях сравниваются идентификаторы оценок и заданий для обоих учеников. Новая оценка создаёт событие в день **обнаружения**, даже если выставлена задним числом за более ранний урок. Новое домашнее задание создаёт аналогичное событие. События отображаются за сегодня и вчера, прочтение фиксируется при выборе события, а не при открытии списка. Повторное появление ранее обнаруженной записи не должно создавать повторное событие (локальный список известных идентификаторов ограничен 5000 элементами). Хранилище браузерное, не синхронизируется между устройствами. Длительные перерывы между сетевыми снимками и изменения оценок с сохранением идентификатора не обнаруживаются как отдельные события. Push-уведомлений нет. Иконка цельная красная/серая 24 px, кнопка 44 px; правила — в `docs/UI_STANDARD.md`.

## История: новые оценки в списке (1.33.20)

Точка «новая оценка» на плитке в разделе «Оценки» отображается только для оценок, впервые обнаруженных при сетевой синхронизации сегодня или вчера. Используется тот же идентификатор и двухдневная история, что и для уведомлений; дата самого урока не ограничивает показ точки. На первом сетевом снимке исторические оценки не помечаются новыми. Прочтение уведомления не снимает точку до окончания двухдневного периода. Локальная история зависит от браузера и ученика.

## История: серия без троек и двоек (1.33.21; заменена в 1.33.54)

Учебные даты определяются объединением проведённых уроков и расписания, без повторов, в выбранной четверти. Учитываются только даты до сегодняшней; дни без оценок засчитываются, даты без уроков пропускаются. Двойка или тройка прерывает серию, включая оценки, выставленные задним числом. Результат зависит от полноты синхронизированных данных.

## Недельный тренд и фильтры (1.33.22)
График показывает накопительную историю четверти с лёгкой акцентной заливкой под линией, без пунктира. Фильтры «Контрольные» и «Двойки» работают независимо и совместно; средние и прогноз не пересчитываются.

«Что нового»: колокольчик и счётчик выбранного ребёнка; только новые и исправленные оценки, тип работы сразу в списке. В окне только непрочитанные уведомления, сохраняемые до подтверждения. После подтверждения окно очищается; технический учёт сохраняется для защиты от повторов. Закрытие окна без подтверждения не отмечает уведомления прочитанными. Дата группы — дата оценки в дневнике; обнаружение при синхронизации определяет новизну. Окно ограничено 80% высоты экрана, прокручивается только список.

## Автоматическое обновление данных (1.33.37)

Настройка «Анимации» в профиле позволяет отключить согласованные микроанимации; выбор сохраняется на устройстве.
