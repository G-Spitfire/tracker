# Школа — компактное приложение (демо)

Статус: подготовка реализации, спецификация v1.4 (18.11.2026).

## Назначение
Мобильное веб-приложение с четырьмя вкладками: Главная, Оценки, Расписание, Домашка. Профиль открывается из верхнего правого угла.

## Первая версия
- Только тестовые данные; реальной авторизации и синхронизации нет.
- Несколько детей, переключение в Профиле.
- Общий средний балл — арифметическое **всех** оценок текущей четверти.
- Динамика — среднее оценок последних 3 учебных дней минус общий средний.
- Фильтр контрольных не изменяет средний балл предмета.
- Оценки: от старых слева к новым справа; сегодняшние и вчерашние выделяются акцентом.
- Расписание открывается на сегодняшней дате.
- Темы: системная, светлая, тёмная; четыре акцентных цвета, локальное сохранение.
- Будущий источник данных: «Петербургское образование».

## Размещение
GitHub Pages: `/tracker/school-simple/` после реализации и проверки. Другие каталоги репозитория не изменять.

## План файлов
- `index.html` — оболочка интерфейса
- `styles.css` — адаптивные стили и темы
- `app.js` — логика экранов и вычисления
- `demo-data.js` — тестовые данные для нескольких детей

Папка создана отдельно; это **ещё не опубликованное работающее приложение**.
