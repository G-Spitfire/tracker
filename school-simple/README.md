# Школа

**Стабильная версия в `main`:** 1.32.5. **Исправление подписи профиля:** 1.32.6 в PR #128 (до слияния).  
**Приложение:** https://g-spitfire.github.io/tracker/school-simple/  
**Основная ветка:** `main`  
**Источник данных:** электронный дневник Санкт-Петербурга — https://dnevnik2.petersburgedu.ru/

«Школа» — PWA для просмотра реальных оценок, расписания и домашних заданий двух учеников. Демонстрационные данные в рабочем приложении удалены. Сквозная проверка сбора, шифрования, публикации снимка и совпадения расшифрованных данных с локальным источником выполнена. Пользователь проверил открытие приложения на Mac и iPhone.

## Состав приложения

Исходный код интерфейса находится в `school-simple/index.html`. Дополнительные файлы:

- `school-sync-client.js` — загрузка зашифрованного снимка, расшифровка и локальный кэш.
- `sw.js` — Service Worker и офлайн-кэш оболочки приложения.
- `version.json` — версия для проверки обновлений.
- `manifest.webmanifest` — настройки PWA.
- `brand-mark.svg`, `icon.svg`, PNG-иконки — фирменный знак и иконки приложения.
- `DESIGN_SYSTEM.md` — актуальные правила интерфейса.
- `AUDIT.md` — техническая ревизия, найденные вопросы и план следующих проверок.

В приложении четыре основных раздела: **Главная / Оценки / Расписание / Домашка**. На главной линейный график выбран по умолчанию; кольцевой доступен переключателем. Статус синхронизации отображает зелёную отметку при получении свежего снимка, жёлтый статус при использовании сохранённого снимка и отдельное сообщение при ошибке. Профиль открывается отдельной кнопкой в заголовке. В профиле доступны выбор ученика, системная/светлая/тёмная тема и четыре акцентных цвета.

## Данные и синхронизация

1. Локальный сборщик на Mac получает данные из электронного дневника.
2. Исходный JSON остаётся на Mac и не публикуется в репозитории.
3. `school-sync/publish.py` нормализует данные и шифрует снимок AES-256-GCM.
4. В отдельную ветку `school-data` отправляется только `data.enc.json`.
5. Браузерный клиент загружает снимок, запрашивает пароль шифрования при первом подключении, расшифровывает данные и сохраняет снимок и ключ CryptoKey в IndexedDB.
6. При открытии приложение сначала показывает ранее сохранённый снимок из IndexedDB, если он есть, и параллельно получает свежие данные. После успешного обновления экран перерисовывается автоматически. Если кэша ещё нет, показывается фирменная заставка загрузки; при ошибке без кэша доступна повторная попытка. При ошибке сети с кэшем приложение продолжает показывать сохранённые данные.

Пароль не хранится в исходном коде или репозитории. На Mac он хранится в Keychain. Ключ шифрования в браузере сохраняется как неэкспортируемый CryptoKey; пароль в открытом виде не сохраняется. Публично доступен только шифротекст, однако его конфиденциальность зависит от надёжного уникального пароля.

## Локальный сборщик на Mac

Сборщик и его окружение находятся вне репозитория:

| Назначение | Путь |
|---|---|
| Сборщик | `~/Library/Application Support/SchoolDiary/collector.py` |
| Python / Playwright | `~/school-diary-venv/` |
| Профиль Chrome | `~/.school-diary-browser-profile/` |
| Исходный JSON | `~/school-diary-data.json` |
| LaunchAgent | `~/Library/LaunchAgents/local.school.diary.collector.plist` |
| Журнал | `~/Library/Logs/school-diary-collector.log` |
| Журнал ошибок | `~/Library/Logs/school-diary-collector-error.log` |

LaunchAgent настроен на будние дни в 12:00, 14:00, 16:00, 18:00 и 20:00 по местному времени Mac. Ручной запуск сборщика и принудительный запуск задания LaunchAgent проверялись. Сам факт длительной стабильной работы всех временных запусков и автоматического восстановления после истечения авторизации требует наблюдения. Если Mac выключен или спит, своевременное выполнение не гарантируется.

Ручная проверка:

```bash
"$HOME/school-diary-venv/bin/python" "$HOME/Library/Application Support/SchoolDiary/collector.py" --non-interactive
tail -n 30 ~/Library/Logs/school-diary-collector.log
launchctl print gui/$(id -u)/local.school.diary.collector
```

Профиль Chrome и исходный JSON содержат персональные данные и/или авторизационную информацию. Не добавлять их в Git, не публиковать и не прикладывать к публичным задачам.

## Правила расчётов и ограничения

- Общий средний балл на главной рассчитывается как среднее арифметическое предметных средних, а не как среднее всех оценок подряд.
- Оценки распределяются по четвертям по заданным в коде календарным диапазонам учебного года 2026/2027. Это локальная календарная классификация, а не отдельное поле четверти из источника дневника.
- Прогноз четвертной оценки — предварительная эвристика с порогами 2,60 / 3,60 / 4,60. Это не официальный расчёт школы.
- Показатель «Под риском» использует средний балл предмета ниже 3,60 и также является ориентиром, а не официальным статусом.
- Динамика — разница между текущим накопительным средним за четверть и накопительным средним по предметам на дату семь календарных дней назад в пределах той же четверти. Если на контрольную дату оценок ещё не было, отображается «—».
- Серия дней без троек и двоек считается по датам проведённых уроков: отсутствие оценок в учебный день не прерывает серию; тройка или двойка в этот день прерывает её.
- Источник не предоставляет подтверждённую дату сдачи домашнего задания в используемом формате. Приложение оценивает срок по следующему запланированному уроку того же предмета. Эта дата может отличаться от официального срока.
- Динамика и серия дней покрыты автоматическими регрессионными тестами; пользователь подтвердил корректность динамики у обоих детей после выпуска 1.32.5.
