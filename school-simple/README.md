# Школа — мобильное приложение (демоверсия)

Статус: работающая демоверсия v1.14, 18.11.2026. Интерфейс: https://g-spitfire.github.io/tracker/school-simple/

## Экраны
- Главная: шесть KPI-плиток (2 × 3), переключатель линейного и кольцевого графиков, диаграммы по оценкам.
- Оценки: список предметов и оценок, фильтр «Все / Контрольные», подробности по нажатию.
- Расписание: недельный календарь и уроки по дням.
- Домашка: задания на ближайший учебный день, на 7 календарных дней, все будущие.
- Профиль: переключение детей, системная/светлая/тёмная темы, четыре акцента.

## Правила расчёта главной
1. **Средний балл**: арифметическое всех оценок ученика за рассматриваемый период (в демо — весь доступный набор).
2. **Динамика за сегодня**: текущий общий средний минус средний по оценкам с датой раньше сегодняшней; при отсутствии сегодняшних или прежних оценок — 0,00. Стрелки ↑ / ↓ / → соответствуют знаку изменения.
3. **Доля пятёрок**: количество оценок 5 / общее количество оценок × 100%, округление до целого процента.
4. **Под риском**: количество предметов со средним ниже 3,60 (временная демо-эвристика для ожидаемой итоговой оценки ниже 4, не официальный прогноз). Порог и метод прогноза подлежат утверждению.
5. **Без троек и двоек**: число последовательных дат с оценками, начиная с последней такой даты, на которых нет оценок 2 или 3. Даты без оценок не увеличивают и не прерывают серию. В интерфейсе подписано «Дней с оценками подряд».
6. **Средний за домашки**: среднее оценок с признаком `homework: true`; если таких оценок нет, показывать «—». Демо-данные содержат искусственно размеченные домашние работы, реальные данные пока не подключены.

Показатели рассчитываются отдельно для выбранного ребёнка. Демо-данные генерируются локально относительно текущей даты.

## Данные и ограничения
- Данные тестовые; авторизации и синхронизации пока нет.
- Предполагаемый источник будущей интеграции: «Петербургское образование».
- Оценки выводятся от старых к новым; сегодняшние и вчерашние выделяются акцентом.
- Фильтр контрольных не меняет общий средний предмета.
- Настройки темы и акцента сохраняются локально.
- Дизайн-система: [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md).
- Код приложения сейчас расположен в одном `index.html` (встроенные CSS и JS); `manifest.webmanifest` и `version.json` — отдельные файлы.
