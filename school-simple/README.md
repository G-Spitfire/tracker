**Адрес:** https://g-spitfire.github.io/tracker/school-simple/  
**Статус ветки `main`:** рабочая PWA 1.31.8 с демонстрационными данными. **Статус ветки `feature/real-diary-integration`:** тестовая 1.32.3 с загрузкой и расшифровкой снимка дневника, отображением оценок, домашних заданий и расписания. ## Приложение

Исходный код интерфейса: `school-simple/index.html` (HTML, CSS, JavaScript). Публикация — GitHub Pages. Версия для проверки обновлений — `version.json`; манифест — `manifest.webmanifest`.

- **Главная:** сводные показатели, распределение оценок, график среднего балла.
- **Оценки:** список, фильтр контрольных, прогноз и график по предметам; выбор четверти.
- **Расписание:** недельный календарь, уроки выбранного дня.
- **Домашка:** ближайший учебный день, неделя, будущие задания.
- **Профиль:** выбор ребёнка, темы и акцентные цвета, версия и Spitfire Studio.

Фирменный знак «Ш» — `brand-mark.svg`; PWA-иконки — `icon.svg`, `icon-180.png`, `icon-192.png`, `icon-512.png`. Действующие визуальные правила: [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md).

Параметры оформления сохраняются локально в браузере. Механизм проверки новой версии использует `version.json`. Не изменять версионирование и рабочую логику без проверки JavaScript и запуска PWA.

## Данные и расчёты

В версии 1.32.3 демонстрационные данные удалены. При первой неудачной загрузке показывается ошибка с возможностью повторить запрос; при ошибке обновления используются ранее сохранённые реальные данные. В ветке интеграции приложение пытается получить зашифрованный снимок из `school-data`; при ошибке первой загрузки показывает сообщение и кнопку повторной попытки, а при ошибке обновления ранее сохранённого снимка используется локальный кэш. Прогноз четвертных оценок и показатель «под риском» — предварительные эвристики, не официальный расчёт школы. Пороги прогноза 2,60 / 3,60 / 4,60 требуют согласования. Выбор четверти в демоданных не означает полноценную разбивку реальных оценок по периодам.

## Локальный сбор реального дневника (Mac)

**Статус:** после переноса сборщика в служебную папку macOS ручной запуск успешно проверен, включая получение данных обоих детей и обновление JSON; автоматическое расписание зарегистрировано. Принудительный запуск через LaunchAgent проверен; фактическое срабатывание всех временных интервалов отдельно не наблюдалось. Длительная стабильность и повторная авторизация после истечения сессии ещё не подтверждены.

Источник: электронный дневник Санкт-Петербурга `https://dnevnik2.petersburgedu.ru/`. Сборщик использует Playwright и отдельный сохранённый профиль Chrome, получает оценки, уроки и домашние задания для двух детей. При последнем успешном тесте получено 160 и 179 оценок, 66 и 91 урок, 57 и 72 задания соответственно. Это результат конкретного запуска, а не гарантированный постоянный объём данных.

**Локальные пути на Mac пользователя:**

| Назначение | Путь |
|---|---|
| Действующий сборщик | `~/Library/Application Support/SchoolDiary/collector.py` |
| Среда Python / Playwright | `~/school-diary-venv/` |
| Профиль Chrome / авторизация | `~/.school-diary-browser-profile/` |
| Результат сбора | `~/school-diary-data.json` |
| Расписание macOS | `~/Library/LaunchAgents/local.school.diary.collector.plist` |
| Журнал | `~/Library/Logs/school-diary-collector.log` |
| Журнал ошибок | `~/Library/Logs/school-diary-collector-error.log` |

**Расписание:** понедельник–пятница, 12:00, 14:00, 16:00, 18:00, 20:00 **по местному времени Mac**. Запуск через пользовательский `launchd` (LaunchAgent). При выключенном или спящем Mac своевременный сбор не гарантируется. Без сети или при истёкшей авторизации свежие данные не поступят; необходимо проверять журнал. При неуспешном сборе прежний JSON сохраняется.

**Ручная проверка:**

```bash
"$HOME/school-diary-venv/bin/python" "$HOME/Library/Application Support/SchoolDiary/collector.py" --non-interactive
tail -n 30 ~/Library/Logs/school-diary-collector.log
launchctl print gui/$(id -u)/local.school.diary.collector
```

В рабочем файле сборщика используется `headless=True`; после переноса получение данных подтверждено, но отсутствие видимого окна Chrome при этом запуске отдельно не подтверждалось. Вход через Госуслуги при необходимости выполняется отдельно в видимом браузере.

**Безопасность:** `school-diary-data.json` и профиль Chrome содержат персональные данные и/или авторизационную информацию. Не коммитить, не публиковать на GitHub Pages и не прикладывать к публичным задачам. Исходный JSON и профиль авторизации должны оставаться локальными. В ветке интеграции `school-sync/publish.py` шифрует нормализованный снимок AES-256-GCM и публикует только шифротекст в ветку `school-data`. Браузерный клиент `school-sync-client.js` расшифровывает его паролем пользователя и сохраняет кэш в IndexedDB. Проверены запуск через LaunchAgent, публикация зашифрованного снимка, совпадение расшифрованных данных с локальным источником и работа приложения офлайн. Срабатывание по расписанию и восстановление после истечения авторизации ещё не подтверждены. Даже шифротекст публично доступен, поэтому необходим надёжный уникальный пароль.
