# Школа — итог технической ревизии

**Дата ревизии:** 19 ноября 2026 года  
**Стабильная версия на момент первоначальной ревизии:** 1.32.6; финальный релиз этапа интерфейса — 1.32.8  
**Публикация:** PR #128 объединён после успешных автоматических проверок  
**Область:** `school-simple/`, `school-sync/`, документация, ветки GitHub и локальная интеграция Mac.

## 1. Итог

Ревизия приложения и структуры репозитория проведена. Исправления 1.32.4, 1.32.5 и 1.32.6 опубликованы в `main`; автоматические проверки прошли успешно. Пользователь подтвердил работу приложения, корректную динамику за семь дней для обоих детей и получение обновлённого снимка после запуска синхронизации около 18:00 19 ноября 2026 года.

Отдельно обнаружена устаревшая подпись «Версия 1.32.4» в профиле после выпуска 1.32.5. Исправление подписи и выпуск PWA 1.32.6 объединены в `main` через PR #128 после успешных автоматических проверок. Также реализованы показ сохранённых данных до сетевого обновления, имя ученика в шапке главной и два новых акцентных цвета.

## 2. Изменения приложения

- Общий средний балл рассчитывается как среднее арифметическое средних по предметам.
- Показатель «Динамика» сравнивает текущее накопительное среднее за четверть с накопительным средним на дату семь календарных дней назад. При отсутствии базовых оценок отображается «—».
- Линейный график строится на той же формуле среднего по предметам, что и главный показатель.
- «Без троек и двоек» считает последовательные даты проведённых уроков, включая дни без оценок.
- Линейный график выбран по умолчанию; кольцевая диаграмма доступна вручную.
- Домашние задания привязаны к следующему запланированному уроку предмета; эта дата не объявляется официальным сроком сдачи. Задания без известного следующего урока остаются во вкладке «Всё».
- «На неделю» показывает задания для пяти ближайших учебных дат из фактического расписания.
- Статус синхронизации различает свежие данные, сохранённый кэш и ошибку загрузки.
- Публикатор блокирует снимок без пригодных оценок после нормализации.

## 3. Проверки

- Проверки синтаксиса JavaScript и Python-публикатора в GitHub Actions.
- Автоматические регрессионные тесты расчётов и домашней работы, включая случаи изменения среднего за семь дней и отсутствия базовых оценок.
- Браузерная smoke-проверка навигации, оценок, домашних заданий и переключения учеников на синтетических данных.
- Пользовательская проверка приложения и динамики обоих детей.
- Пользовательская проверка обновления данных около 18:00 19 ноября 2026 года.

Проверка одного успешного цикла синхронизации не гарантирует будущую работу при спящем Mac, истёкшей сессии электронного дневника или сетевом сбое. Эти ситуации остаются предметом эксплуатационного наблюдения.

## 4. Репозиторий и резервные копии

- Дублирующая папка `school-preview/` удалена из `main`; её файлы совпадали с рабочими копиями.
- Исправления объединены с `main` через PR #126, PR #127 и PR #128 методом squash.
- После уборки в GitHub остались две ветки: `main` (приложения) и `school-data` (зашифрованные данные дневника). Устаревшие и архивные ветки удалены.
- На Mac была создана резервная папка `~/Desktop/School-Cleanup-Backup-20261119/` с архивом старых версий сборщика и Git bundle. Решение об удалении локальной копии принимается отдельно.
- Локальный рабочий сборщик, LaunchAgent, Chrome-профиль, Keychain и соль шифрования не удалялись и не изменялись в рамках ревизии.

## 5. Сохраняемые ограничения

- Календарные диапазоны четвертей заданы в коде для 2026/2027 учебного года; перед новым учебным годом их нужно пересмотреть.
- Прогноз четвертной оценки использует эвристические пороги 2,60 / 3,60 / 4,60 и не является официальным расчётом школы.
- Подтверждённой официальной даты сдачи домашней работы в используемом источнике нет.
- При длительной эксплуатации нужно наблюдать восстановление авторизации сборщика и обновление PWA на устройствах.

## 6. Закрытие ревизии

PR #128 объединён. Отображение версии 1.32.6 в установленной PWA на устройстве пользователя остаётся проверить отдельно. Дальнейшие изменения приложения выполнять отдельными задачами с тестами и обновлением документации.
