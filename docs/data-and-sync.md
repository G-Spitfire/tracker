# Хранение данных и школьная синхронизация

## Где находятся данные

| Приложение | Основные локальные данные | Резервная копия / синхронизация |
| --- | --- | --- |
| Искра | Дела, отметки, профиль и награды в `kid1`; резерв — `kid1_bak` | JSON в разделе «Я → Для родителей». Оценки — Firebase; офлайн-копия оценок включается отдельно и не шифруется. |
| Вектор | Задачи, проекты и виджеты в `vektor_logic_mvp_2026_10`; резерв — суффикс `_bak` | JSON в настройках. Оценки — Firebase; задачи и проекты не синхронизируются. |
| Ритм | Данные профиля и привычек в `wife3`; резерв — `wife3_bak` | Экспорт и восстановление JSON из настроек профиля. |
| Форма | Данные тренировок в `forma12_v1`; оформление — отдельно в `forma_theme` | Резервная копия JSON; автоматической синхронизации нет. |
| WordScene | Прогресс и незавершённое занятие в `word-scenes-v5` | Автоматической синхронизации и отдельного экспорта нет. Переходы старых форматов выполняются в приложении. |
| Покер с нуля | Просмотр разделов и учебного примера в `pokerGuideReadV2` и `pokerPracticeDoneV2` | Только текущий браузер; серверной синхронизации нет. |

Ключи приведены для документации и должны сохраняться при изменениях. Не очищайте хранилище браузера как способ обновления приложений. При переустановке ярлыка или переносе на другое устройство не полагайтесь на автоматический перенос: сначала экспортируйте JSON там, где он доступен, затем восстановите его в новой установке. Для WordScene отдельного экспорта нет — сохраните прежний браузер/ярлык, пока не проверите прогресс после обновления.

Оценки из школьного дневника принадлежат Firebase и не включаются в резервные копии локальных задач. После переустановки может потребоваться повторный вход в школьный раздел.

## Школьные оценки

Вектор и Искра подключают [`../shared/school-cloud.js`](../shared/school-cloud.js). Модуль использует Firebase Authentication и Firestore. Для каждого приложения создаётся отдельный экземпляр Firebase (`school-vector` и `school-iskra`), поэтому их сессии входа разделены.

После входа клиент запрашивает только документ `schoolGrades/{auth.uid}` текущего пользователя. Он не перечисляет коллекцию, не записывает оценки и не получает школьные пароли, cookies или идентификаторы входа. Загрузка данных в Firestore выполняется отдельно на MacBook через Google ADC/IAM; нажатие «Обновить» в приложении только повторно читает Firestore и не запускает сбор с сайта школы.

Firestore-правила и учётные данные синхронизации не хранятся в этом репозитории. Не добавляйте в GitHub резервные копии, школьные выгрузки, UID-привязки, ADC-файлы или cookies. Фактические правила доступа настраиваются в Firebase вне кода сайта.

Офлайн-копия оценок реализована только для Искры: она включается отдельно, хранится в незашифрованном `localStorage` и удаляется при отключении этой функции или выходе из школьного аккаунта. Вектор не сохраняет школьные оценки в своём localStorage.

## Публикация и адреса

GitHub Pages раздаёт статические файлы из основной ветки. Сборка и сервер приложения не нужны. Перемещение страницы внутри того же сайта не меняет сами ключи хранения, но поведение локального хранилища может зависеть от браузера и способа установки ярлыка; для важных данных используйте штатный экспорт и восстановление.
