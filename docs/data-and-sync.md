# Хранение данных и резервные копии

| Приложение | Основные локальные данные | Резервная копия / синхронизация |
| --- | --- | --- |
| Форма | Тренировки в `forma12_v1`; оформление в `forma_theme` | Резервная копия JSON; автоматической синхронизации нет. |
| WordScene | Прогресс и незавершённое занятие в `word-scenes-v5` | Автоматической синхронизации и отдельного экспорта нет. Миграции старых форматов выполняются в приложении. |
| Левели (ветка `leveli-core`) | Firebase Auth; Firestore `schoolGrades/{uid}` и `profiles/{uid}` | Оценки и профиль читаются из облака; WordScene пока не синхронизирован с Левели. Проверено локально, не опубликовано в `main`. |
| Покер с нуля | Просмотр разделов и учебного примера в `pokerGuideReadV2` и `pokerPracticeDoneV2` | Только текущий браузер; серверной синхронизации нет. |

Не очищайте хранилище браузера как способ обновления приложений. При переустановке ярлыка или переносе на другое устройство не полагайтесь на автоматический перенос: сначала экспортируйте JSON там, где он доступен, затем восстановите его в новой установке. Для WordScene отдельного экспорта нет — сохраните прежний браузер/ярлык, пока не проверите прогресс после обновления.

## Публикация и адреса

GitHub Pages раздаёт статические файлы из основной ветки. Сборка и сервер приложения не нужны. Перемещение страницы внутри того же сайта не меняет сами ключи хранения, но поведение локального хранилища может зависеть от браузера и способа установки ярлыка; для важных данных используйте штатный экспорт и восстановление.
