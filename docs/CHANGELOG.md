# Краткая история изменений

Обзор заметных обновлений действующих приложений. Полная история изменений доступна в [Git](https://github.com/G-Spitfire/tracker/commits/main).

## Октябрь 2026

- **Левели (`leveli-core`, не `main`):** локально проверены вход, чтение школьных оценок и отображение имени из `profiles/{uid}`; зафиксирована диагностика устаревшей локальной копии и ошибочного URL с невидимым символом. Отдельная проверка Матвея и публикация ещё не подтверждены. Подробнее: [leveli/README.md](../leveli/README.md).


- **Форма:** обновлены управление тренировкой и редактор плана; добавлены пауза, отдых между упражнениями и проверка резервных JSON-копий.
- **WordScene:** обновлена очередь повторений, сохранение незавершённых занятий и письменная проверка новых слов.
- **Репозиторий:** приложения разложены по отдельным папкам; добавлена общая страница каталога и описание архитектуры данных.
