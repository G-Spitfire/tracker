# WordScene 17.0

Автономное PWA-приложение для изучения английских слов одним ребёнком на одном устройстве.

[Открыть WordScene 17](https://g-spitfire.github.io/tracker/wordscene/)

- Все учебные данные сохраняются только локально. Firebase, регистрация, синхронизация и несколько аккаунтов не используются.
- Экран и редактирование профиля удалены; исторические поля сохранения остаются нетронутыми для совместимости.
- Главная автоматически обновляет очередь при смене локальной даты и возвращении в приложение. Нижняя навигация учитывает высоту экрана и безопасную зону телефона; нижний декоративный пейзаж убран.
- Приложение автоматически сохраняет текущее место, включая подбор. Незавершённая попытка остаётся доступной до завершения или подтверждённой отмены. Завершённый прогресс сохраняется.
- Запоминание оформлено в согласованном Paper: материалы карточки прокручиваются отдельно, действия остаются внизу экрана. Следующее слово открывается сверху; иллюстрация и ассоциация сразу видны отдельно от двустороннего листа.
- Словарь, темы, иллюстрации и иконки PWA находятся внутри `wordscene/`, зависимости от каталога WordScene 16.17 отсутствуют.
- Механика повторений, уровни и утверждённый Paper-дизайн описаны в [SPEC.md](SPEC.md).
- Сведения о происхождении словарных материалов и графики: [ATTRIBUTION.md](ATTRIBUTION.md).

Запуск: статический сервер из корня репозитория, открыть `/wordscene/`. Проверки: `node --test wordscene/*.test.cjs`.

WordScene 17 принята для повседневного использования и опубликована из `main`. Каталог `wordscene/` задаёт постоянный короткий адрес приложения. При смене адреса с `/wordscene-17-lab/` сохранения не переносятся — новый старт.


Актуальная спецификация — только [SPEC.md](SPEC.md). Проверки браузеров и офлайн-режима: `node wordscene/browser-acceptance.cjs` при установленном Playwright; `WS17_TEST_ORIGIN=https://g-spitfire.github.io/tracker` проверяет опубликованную версию. Физический iPhone автоматическими проверками не покрыт.
