# WordScene

Текущая версия: **16.12**, 2 ноября 2026 года.

Последние функциональные обновления: **3 ноября 2026 года**. Версия релиза 16.12 пока не изменена.

Офлайн-кэш: `wordscene-v16-22-20261103-four-tab-navigation` (обновлён 3 ноября после изменений занятий и статистики). Номер кэша используется для обновления автономных ресурсов и не является номером релиза.

[Открыть приложение](https://g-spitfire.github.io/tracker/wordscene/)

Самостоятельный тренажёр с 500 английскими словами: переводом, транскрипцией, историей и иллюстрацией. Сборка и установка зависимостей не нужны.

## Занятия

На главной доступны начало и продолжение занятия. Приложение сначала предлагает обязательные повторения, затем новые слова. Новая подборка содержит до пяти слов; повторение — до 30 уникальных слов за подход, с отдельным учётом направлений и возможностью перейти к следующей порции. Пауза сохраняет место. В словаре есть поиск, темы и фильтры ошибок.

Новые слова проходят знакомство, устные проверки в обе стороны и проверку написания. В каждом устном направлении минимум три прохода; два последних — без ошибок. Ошибочные написания получают ещё две проверки. Обычное повторение остаётся устным в обе стороны. За завершённые занятия отмечается день; ошибки не мешают его засчитать.

## Достижения и статистика

Главный экран показывает недельную активность с увеличенными фиолетово-розовыми кольцами; период недели и легенда находятся в одной строке, соседние недели переключаются горизонтальным свайпом (или стрелками клавиатуры), будущие недели недоступны. Компактная карточка достижений с тремя показателями в строку использует тот же светло-фиолетовый фон. Из подробного экрана достижений удалён предварительный график ежедневного количества изученных слов. Сохранён график накопительного роста словаря; для старых записей без даты обучения показывается исходная база, а недоступные исторические значения не подменяются выдуманными числами. С 3 ноября 2026 года сохраняются завершённые занятия и идентификаторы изученных слов по дням для более точной истории.

## Навигация, настройки и профиль

На основных экранах закреплено нижнее меню: «Главная», «Словарь», «Статистика», «Настройки». Во время обучения нижнее меню скрывается; верхняя панель содержит только логотип. «Мои достижения» открываются вкладкой «Статистика».

Настройки включают звуковые сигналы и профиль. До авторизации в профиле показывается приглашение войти в аккаунт; редактирования имени нет. После входа отображаются имя из Firebase Auth (если задано), аккаунт, статус облачной синхронизации и дата/время последнего подтверждённого успешного обмена **в текущей сессии приложения**. Время не выдумывается: до первой подтверждённой синхронизации отображается соответствующее сообщение. Имя не редактируется внутри приложения. При конфликте и повреждении данных открывается отдельное окно восстановления.


## Сохранение прогресса

Заниматься можно без аккаунта. Прогресс сохраняется в localStorage этого браузера под ключом `word-scenes-v5`. Очистка данных браузера удаляет локальную копию.

После входа в аккаунт прогресс сохраняется автоматически без ручных кнопок. Облачная копия отправляется примерно через минуту после изменений, раньше — при завершении занятия или паузе. На новом телефоне после входа в тот же аккаунт пустой профиль автоматически восстанавливается из облачной копии с сохранением возможности отката. Если на устройстве уже есть занятия, прогресс не перезаписывается: обе версии сохраняются, а разбор конфликта доступен взрослому.

При обычной работе в аккаунте отображаются вход, статус сохранения и выход. При конфликте или повреждении данных отдельно открывается аварийное окно со средствами восстановления: можно скачать копию устройства, восстановить JSON и отменить последнее восстановление. Поддерживаются обычные файлы `wordscene-backup` и архивы `wordscene-conflict` с выбором версии. Предыдущая исправная копия остаётся для отката; повреждённые исходные данные сохраняются отдельно. История конфликтов ограничена тремя парами и 2 МиБ.

Гость и аккаунты имеют отдельные локальные профили. При первом входе из гостевого режима с изученными словами взрослому предлагается привязать текущий прогресс к новому локальному профилю аккаунта; исходная гостевая копия сохраняется. Если аккаунт уже имеет локальный профиль, автоматического переноса нет. При наличии другой облачной копии версия не заменяется без безопасного разбора конфликта. Миграции старых сохранений сохранены. Обновление приложения не должно очищать прогресс или менять идентификаторы слов.

## Файлы текущего приложения

- `index.html` — интерфейс и управление занятием.
- `content.js`, `topics.js` — текущие 500 карточек и темы.
- `review-engine.js`, `writing-engine.js`, `habit-engine.js` — повторение, написание и регулярность.
- `state-guard.js`, `profile-store.js` — проверка сохранений и локальные профили.
- `cloud-firestore.js`, `cloud-sync.js`, `cloud-ui.js` — облачные копии и вход.
- `backup-local.js`, `backup-ui.js` — файлы, восстановление и откат.
- `sw.js`, `manifest.webmanifest`, `assets/` — автономная работа, установка и изображения.

После полного первого открытия материалы кэшируются для работы без интернета. Для входа и облачного сохранения нужна связь. Закрытое приложение не выполняет фоновых задач. Чтобы получить обновление, откройте его с интернетом; очищать данные браузера не нужно.
