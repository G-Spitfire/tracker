# WordScene

Текущая версия: **16.12**, 2 ноября 2026 года.

Офлайн-кэш: `wordscene-v16-13-home-cleanup` (обновлён 2 ноября 2026 года после изменений главного экрана). Номер кэша используется для обновления автономных ресурсов и не является номером релиза.

[Открыть приложение](https://g-spitfire.github.io/tracker/wordscene/)

Самостоятельный тренажёр с 500 английскими словами: переводом, транскрипцией, историей и иллюстрацией. Сборка и установка зависимостей не нужны.

## Занятия

На главной доступны начало и продолжение занятия. Приложение сначала предлагает обязательные повторения, затем новые слова. Новая подборка содержит до пяти слов; повторение — до 15 слов за подход. Пауза сохраняет место. В словаре есть поиск, темы и фильтры ошибок.

Новые слова проходят знакомство, устные проверки в обе стороны и проверку написания. В каждом устном направлении минимум три прохода; два последних — без ошибок. Ошибочные написания получают ещё две проверки. Обычное повторение остаётся устным в обе стороны. За завершённые занятия отмечается день; ошибки не мешают его засчитать.

## Сохранение прогресса

Заниматься можно без аккаунта. Прогресс сохраняется в localStorage этого браузера под ключом `word-scenes-v5`. Очистка данных браузера удаляет локальную копию.

После входа в аккаунт доступны **«Сохранить прогресс»** и **«Восстановить прогресс»**. Автокопия отправляется примерно через минуту после изменений, раньше — при завершении занятия или паузе. Для переноса на новый телефон взрослый входит в тот же аккаунт и подтверждает восстановление. Разные версии не объединяются и не заменяются молча.

В настройках, в разделе **«Файлы и откат»**, можно скачать копию устройства, восстановить JSON и отменить последнее восстановление. Поддерживаются обычные файлы `wordscene-backup` и архивы `wordscene-conflict` с выбором версии. Предыдущая исправная копия остаётся для отката; повреждённые исходные данные сохраняются отдельно. История конфликтов ограничена тремя парами и 2 МиБ.

Гость и аккаунты имеют отдельные локальные профили. Миграции старых сохранений сохранены. Обновление приложения не должно очищать прогресс или менять идентификаторы слов.

## Файлы текущего приложения

- `index.html` — интерфейс и управление занятием.
- `content.js`, `topics.js` — текущие 500 карточек и темы.
- `review-engine.js`, `writing-engine.js`, `habit-engine.js` — повторение, написание и регулярность.
- `state-guard.js`, `profile-store.js` — проверка сохранений и локальные профили.
- `cloud-firestore.js`, `cloud-sync.js`, `cloud-ui.js` — облачные копии и вход.
- `backup-local.js`, `backup-ui.js` — файлы, восстановление и откат.
- `sw.js`, `manifest.webmanifest`, `assets/` — автономная работа, установка и изображения.

После полного первого открытия материалы кэшируются для работы без интернета. Для входа и облачного сохранения нужна связь. Закрытое приложение не выполняет фоновых задач. Чтобы получить обновление, откройте его с интернетом; очищать данные браузера не нужно.
