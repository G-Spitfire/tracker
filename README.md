## Ритм

Приложение привычек с мятной палитрой и иконкой из трёх волн.

- Лента дня с привязками «после события → действие», временем и рабочими часами.
- Создание и редактирование привязок, выбор дней недели, отметка выполнения и её отмена.
- Возможность временно поставить действия на паузу. Архив привязок сохраняет прошлые результаты в отчётах; период в архиве исключён из плана, привязку можно вернуть.
- Профиль с именем и аватаркой.
- Статистика за эту неделю, прошлую неделю и последние 30 дней: общий итог и результаты каждой привычки. Недельные отчёты также показывают дни выполнения.
- Будущие дни не увеличивают текущий план. История старше 30 дней сохраняется.
- Настройка рабочего расписания. Напоминания требуют добавления в Календарь: рядом с переключателем есть пояснение и кнопка сохранения с экспортом выбранной привязки. Изменения приложения не синхронизируются с ранее добавленными событиями.
- Копия данных и восстановление из JSON-файла; поддержано восстановление старого текста. Перед заменой прежнее состояние сохраняется в `wife3_before_restore`.
- Светлая тема и тёмная тема с графитовыми поверхностями, контрастными границами элементов и мятными акцентами.

## Искра

- Дела дня, звёзды, награда недели и профиль Полины. Изменение награды, цели по звёздам и копии данных находятся в разделе «Для родителей» внутри «Я» (без пароля).
- Выполненные дела сохраняют контрастный текст в обеих темах. Отметку можно снять отдельно у каждого дела; массового сброса дня нет.
- Раздел «Оценки»: добавление, исправление и удаление оценок по предметам.
- Средние баллы, график изменений, диаграмма прогноза итоговых оценок и подсказки по улучшению — расчёты как в «Векторе».
- Пороги прогноза: 2,6 / 3,6 / 4,6. Оценки равновесные; школьные правила могут отличаться.
- Управление предметами и датой конца четверти. Архив сохраняет оценки, исключая предмет из текущего прогноза.
- Основные данные остаются в `kid1`; оценки хранятся также в `kid1_school` и входят в общую JSON-копию. Поддерживаются файлы и старые текстовые копии. Копии без оценок сохраняют текущие школьные записи. Перед восстановлением предыдущие данные сохраняются в `kid1_before_restore`.

## Вектор

- Предметы архивируются вместе с оценками; архив исключён из прогноза, восстановление возвращает все оценки.
- Галочка количественной привычки появляется только при достижении цели; до этого виден результат «10 из 30».
- Список и счётчик задач относятся к выбранному дню: выполненные в этот день и невыполненные без срока либо со сроком не позднее выбранной даты.

## Данные

Данные приложений хранятся в браузере на устройстве. Для переноса используется резервная копия.

У «Ритма» основной ключ localStorage — `wife3`. Фото профиля также сохраняется локально и входит в резервную копию.

При обновлениях сохраняем ключи хранения, идентификаторы и историю отметок. Адреса приложений меняем только с планом переноса.
