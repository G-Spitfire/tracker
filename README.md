# Репозиторий приложений

В репозитории находятся несколько самостоятельных проектов. Публичный каталог GitHub Pages показывает три приложения: «Форма», WordScene и «Аспект». Приложение «Школа» опубликовано отдельно и не выводится в общем каталоге.

| Проект | Назначение | Адрес | Документация |
| --- | --- | --- | --- |
| Форма | Трекер тренировок | [Открыть](https://g-spitfire.github.io/tracker/forma/) | [README](forma/README.md) |
| WordScene | Изучение английских слов | [Открыть](https://g-spitfire.github.io/tracker/wordscene/) | [README](wordscene/README.md) |
| Аспект | Планировщик школьного расписания | [Открыть](https://g-spitfire.github.io/tracker/school-aspect/) | [README](school-aspect/README.md) |
| Школа | Электронный дневник семьи на основе данных Петербургского образования | [Открыть](https://g-spitfire.github.io/tracker/school-simple/) | [README](school-simple/README.md) |

Другие папки содержат исходные материалы, служебные инструменты и отдельные компоненты проектов. Не все папки репозитория являются самостоятельными опубликованными приложениями.

Большинство приложений публикуются как статические сайты через GitHub Pages. Технические детали и правила хранения данных описаны в README соответствующих проектов.
