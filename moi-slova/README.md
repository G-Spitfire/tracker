# Мои слова

https://g-spitfire.github.io/tracker/moi-slova/

Мобильное PWA с 10 тестовыми словами. Самостоятельная адаптация открытых приёмов Николая Ягодкина/Advance, не официальный продукт. Содержание демонстрационное; созвучия приблизительны, произношение нужно слушать.

## Процесс
1. Разобрать 10 карточек с русского. Вправо — знаю, влево — буду учить; тап открывает английский ответ по желанию.
2. Учить незнакомые в пределах дневной нормы (1–10, по умолчанию 5). Слово, перевод, оригинальная векторная сцена и звуковая опора. Представить сцену и произнести слово три раза; вверх — дальше.
3. Проверка русского → английского, затем обратно. Тап — ответ, затем вправо — вспомнил, влево — не вспомнил. После ошибки возвращаются сцена и проговаривание; слово появляется через две другие карточки, при короткой очереди раньше.

При перетаскивании показана подпись действия. Короткие/неверно направленные движения не считаются ответом. Сопутствующий click после свайпа подавляется, следующий намеренный тап работает. Доступны кнопки и клавиатура.

## Первичное закрепление и повторение
Для нового слова минимум три круга в каждом направлении. Два последних круга должны быть без ошибок и со стабильным временем воспроизведения (последний не медленнее предыдущего более чем на 25% + 250 мс; среднее до открытия ответа не больше 5 секунд). Это эвристика MVP, а не авторский норматив и не объективная проверка знания. Микрофон не используется.

Не больше шести кругов в направлении. Если свободного воспроизведения пока нет, назначается дополнительное повторение через 20 минут, день не засчитывается как успешное закрепление. Нет видимого таймера, баллов за скорость или штрафов.

Повторное занятие — один проход в каждом направлении. Только забытые слова переходят в повторное запоминание; успешно проверенные назначаются на следующий срок. Знакомые при первом разборе проверяются на следующий день и не тратят дневную норму новых слов.

Первое успешное закрепление — повтор через 20 минут; после дополнительного захода в тот же день — следующий день. Затем ежедневно. «Изучено» — успешное закрепление в семь различных дней и отсутствие последней ошибки. Для изученных — повтор через три дня. Пропуски не штрафуются. При большом числе повторов ребёнок выбирает только повторение либо повторение с новыми словами.

## Данные и ограничения
localStorage `moi-slova-v1`, без Firebase и синхронизации. Имя, норма, история и незавершённое занятие сохраняются. Старые показатели и идентификаторы не удаляются. Старый активный сценарий при переходе на разбор сохранён в previousSession. Очистка данных сайта удалит прогресс.

Профиль: имя, норма, изучено/учу, верные ответы, ошибки, занятия, график за семь дней. Три произнесения и честность самопроверки остаются на ребёнке.

Озвучка — системный speechSynthesis en-GB, по нажатию. Наличие и офлайн-работа голосов зависят от устройства. Десять оригинальных SVG-сцен в scenes/ работают офлайн. Неэффективная шаблонная замена ассоциации убрана.

## Разработка
Статические файлы, сборка и зависимости не нужны. Safari → Поделиться → На экран «Домой». Первый запуск онлайн. Service worker обновляет только собственные кэши.

Проверки из корня репозитория:
- `node moi-slova/tests/paper.cjs`
- `node moi-slova/tests/gestures.cjs`
- `node moi-slova/tests/learning.cjs`

Тесты принимают путь к app.js аргументом. Локально файлы лежат в dist: например, `node tests/learning.cjs dist/app.js` из папки проекта.
Проверены разбор, обучение, жесты, ошибки, норма, завершение, сохранение, миграция; короткое повторение, работа только над забытыми словами, критерий семи дней, ограничение медленного закрепления.


## Обновление: прогресс и свободная тренировка
- Свободная тренировка сегодняшних слов после дневной нормы/исчерпания новых слов. Два коротких направления, ассоциация после ошибки. Новые слова, основной счётчик ответов/ошибок, расписание, уникальные слова дня и дни закрепления не увеличиваются. Отдельно сохраняется число свободных тренировок.
- Четыре состояния: «Знакомо» (первичный разбор), «Запоминаю» (начато/забыто), «Закрепляю» (есть успешные дни), «Изучено» (семь успешных дней, последняя проверка успешна). Ещё не начатые слова не включены в эти показатели.
- Главный результат — уникальные слова дня, дедупликация по идентификатору. Отдельные списки новых и повторённых, а также завершённых новых/повторённых. Старая история общих ответов остаётся в раскрываемом разделе; отсутствующие исторические уникальные данные обозначаются «—» и не восстанавливаются предположениями.
- Семь отметок дней закрепления и список дат для каждого слова. Повторение в тот же день и свободная тренировка не добавляют отметку.
- «Нужна помощь»: последняя неудача либо повторяющиеся ошибки за последнюю неделю; изученные слова исключены. Переход к ассоциации и отдельной свободной тренировке доступен без активного занятия. Расписание не меняется, результат основной проверки сохраняется.
- Удержание: только первый оценённый ответ по слову в новый день, после предыдущего завершённого занятия. Две группы: через 1 день и через 2+ дня. Это самооценка, а не проверка микрофоном. Повторные ответы и свободная тренировка исключены. До накопления данных нет процентов.
- Главная: место остановки, число слов на текущем этапе и «Продолжить»; дневная цель по новым словам (ограниченная наличием слов), результат повторений и следующий срок. Если новых нет — цель по повторению. Показатель общего изученного словаря остаётся в профиле.
- Этапы отличаются цветом/содержимым, геометрия и размер слова внутри проверки не меняются при открытии ответа. Небольшие анимации с поддержкой reduced motion.

Дополнительный тест: `node moi-slova/tests/progress.cjs` (либо путь к app.js аргументом).
