# Мои слова

Мобильное PWA для английских слов: 10 демо-слов, тап для переворота, свайпы для ответа, возврат ошибок, интервалы 1/3/7/14 дней. Профиль с именем и нормой 1–10 новых слов в день (по умолчанию 5). Статистика ответов и занятий за последние дни.

Адрес: https://g-spitfire.github.io/tracker/moi-slova/

В Safari: Поделиться → На экран «Домой». Первый запуск — онлайн; затем файлы доступны офлайн после успешного кэширования.

Данные хранятся локально, ключ `moi-slova-v1`. Синхронизации и Firebase нет. При очистке данных сайта прогресс удаляется. Незавершённое занятие сохраняется. Изучено = слова с успешным последним ответом; повторения продолжаются. Норма новых слов считается по календарному дню устройства. Повторы добавляются сверх нормы. Свайп до открытия ответа только открывает перевод.

Сборка не требуется. Автоматически проверены дневная норма, возврат ошибок, завершение, сохранение и восстановление, все 10 слов; синтаксис JS и service worker.
