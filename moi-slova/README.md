# Мои слова · MVP

Адрес: https://g-spitfire.github.io/tracker/moi-slova/

10 демонстрационных слов. Самостоятельная адаптация открытых приёмов Николая Ягодкина/Advance; не официальный продукт Advance. Ассоциации тестовые: простые сцены из символов и фразы. Звуковые опоры приблизительны и не заменяют произношение.

## Занятие
- Первый разбор: все 10 карточек русской стороной. Вправо — знаю, влево — буду учить; тап открывает английский ответ по желанию.
- После разбора — размеры двух стопок и начало изучения только незнакомых в пределах нормы. Остальные незнакомые остаются на следующие дни.
- Запоминание: английское слово, перевод и ассоциация. Представить сцену и произнести английское слово три раза. Вверх — следующая карточка. Озвучка по нажатию.
- После запоминания всей стопки — проверка: русский → английский, затем английский → русский. Тап открывает ответ, после этого вправо — вспомнил, влево — не вспомнил.
- Ошибка показывает ассоциацию и инструкцию произнести слово три раза. Вверх — продолжить; слово возвращается через две другие карточки.
- При обновлении старое незавершённое занятие сохраняется в previousSession для совместимости, активная работа начинается с нового разбора. Имя, норма и исторические счётчики остаются.
- Знакомые при разборе слова не тратят норму новых, проверка назначается на следующий день. Они не считаются «Изучено» без закрепления по дням.
- Микрофон не используется; произношение и три повторения выполняются самостоятельно. speechSynthesis зависит от голосов устройства.

## Закрепление и расписание
В каждом направлении минимум 3 прохода. Завершение — два чистых прохода подряд, если среднее время последнего не больше предыдущего на 25% + 250 мс. При замедлении повторяем; видимого таймера нет. Это эвристика самопроверки, не объективная проверка знания или речи. Время считается до открытия ответа; ошибка запрещает завершение по скорости. Занятие можно прервать и продолжить автоматически.

Первое закрепление — повтор через 20 минут. После дополнительного захода в тот же день — следующий день. Затем повторения по дням; «Изучено» требует успешного закрепления минимум в три разные даты и минимум шести дней от знакомства. После ошибки слово временно возвращается в «Учу». Для изученных — следующий повтор через 3 дня. Пропуски не штрафуются. При количестве наступивших повторов больше дневной нормы и наличии новых слов ребёнок выбирает: только повторить или добавить новые.

## Данные
Только localStorage, ключ `moi-slova-v1` сохранён. Без Firebase. Имя, норма, счётчики и история старого MVP сохраняются. Старая незаконченная очередь переносится в новый сценарий; старый «знакомый» статус не превращается автоматически в «изучено». Сеансы, ошибки и верные ответы учитываются в профиле вместе с графиком за 7 дней. Очистка данных сайта удаляет прогресс. При переустановке с другого браузера/устройства синхронизации нет.

## Запуск и проверка
Сборка и зависимости не нужны. Статика в этой папке. Установка на iPhone: Safari → Поделиться → На экран «Домой»; первый запуск онлайн. Service worker кэширует приложение и очищает только собственные старые кэши.

Тесты: `node moi-slova/tests/paper.cjs` из корня репозитория (локально: `node tests/paper.cjs dist/app.js` из папки приложения). Тест принимает путь к app.js аргументом. Проверки: этапы, направления, адаптивные проходы, ошибка/возврат, свайпы, норма, пропуск знакомых, завершение, сохранение, миграция.

## Исправление жестов
Один свайп — одно действие. Сопутствующий click после жеста блокируется на уровне страницы, даже при смене карточки. Новый pointerdown начинает отдельный жест/тап. Направление фиксируется после 12 px; порог принятия 50 px. Вертикальное движение не оценивает ответ, короткое и диагональное не засчитываются. До открытия ответа свайп показывает подсказку о тапе. Проверки: `node moi-slova/tests/gestures.cjs`.
