# Семейные приложения — правила работы

Репозиторий: G-Spitfire/tracker. Это несколько самостоятельных семейных приложений.

## Перед изменениями
- Прочитай README.md и актуальный исходный файл выбранного приложения.
- Уточняй приложение по задаче. Не меняй соседние приложения без запроса.
- Проверяй последнюю версию в GitHub; не заменяй её устаревшей локальной копией.
- Не считай исторические идеи из чатов действующими требованиями: ориентируйся на актуальное состояние и новые указания пользователя.

## Продукт и код
- Основной язык интерфейса — русский. Приоритет: простота ежедневного использования на телефоне.
- Добавляй функции только по задаче; при упрощении удаляй связанные обработчики, расчёты и неиспользуемые стили.
- Сохраняй самостоятельность HTML-приложений. Не добавляй сборку, сервер, зависимости и общую архитектуру без необходимости.
- Не возвращай удалённые функции без нового запроса пользователя.

## Данные
- Сохраняй ключи localStorage, идентификаторы, отметки и совместимость резервных копий.
- Изменение интерфейса или периода отчёта не должно удалять историю.
- Удалённые из интерфейса старые поля можно оставлять в сохранённом объекте; не сохраняй ради них неиспользуемый код.
- Не публикуй личные данные, резервные копии, фото и содержимое localStorage в GitHub или в тестовых файлах.
- Для проверок используй искусственные данные. Не меняй реальные пользовательские отметки ради теста.
- При миграции продумывай обратимость и сохранность данных.

## Проверка и публикация
- Проверь синтаксис JS, затронутые сценарии и сохранность старых данных.
- Для изменений интерфейса проверь отображение и основные действия в браузере.
- Убедись, что изменены только нужные файлы.
- Публикуй по существующему адресу, когда публикация входит в запрос или уже согласована в текущей работе.
- Проверь результат публикации. В отчёте различай локальную готовность, коммит и доступность обновления на сайте.
- Обновляй README.md при изменении актуальных функций, адресов или правил хранения.
- Не удаляй приложения по расплывчатому «удали лишнее», если их назначение и ненужность не установлены.
