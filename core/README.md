# CORE 1.0
Светлый автономный трекер привычек. Статический PWA без внешних зависимостей. Целевой экран iPhone 14 Pro (393 × 852 CSS px).

## Публикация
1. Поместить папку core в существующий репозиторий G-Spitfire/tracker, не изменяя другие приложения.
2. Settings → Pages → Deploy from a branch → main / (root).
3. Открыть https://g-spitfire.github.io/tracker/core/ в Safari на iPhone. Поделиться → На экран «Домой» → Добавить.
4. Первый запуск требует сети, затем приложение должно работать офлайн. Экспортируйте резервные копии в настройках.

## Локальная проверка
`python3 -m http.server 8000` из папки core, затем http://localhost:8000. Не открывайте index.html через file://.

## Правила аналитики
Дневной показатель: выполненные дневные цели / запланированные. Гибкие недельные цели отдельно. В итоговый процент включаются только полные календарные недели внутри выбранного периода. График прогресса и карта активности дополнительно учитывают выполненные гибкие цели. Накопленные факты включают все записи периода. Изменение цели действует с текущего дня. Архив сохраняет записи и периоды паузы при восстановлении. Тип привычки после создания не меняется.

## Обновления
При изменении статических файлов увеличивайте CACHE в sw.js. Закройте старые окна приложения, затем откройте заново. IndexedDB сохраняется отдельно от кэша. Сохранение браузером не гарантирует резервное копирование.
