## Что изменено

1. Добавлен model.js: версионированный документ с каталогами групп, сотрудников, помещений, типов и названий активностей. Уроки, перемены/прогулки и мероприятия хранятся одинаково, со ссылками по ID. Совместное событие содержит несколько групп, а не копии записей.
2. Введён адаптер существующего редактора к новой модели. Записи расписания хранят ID, имена разрешаются из справочников при чтении. Новые записи получают UUID. Старые идентификаторы сохранены при переносе.
3. Обновление ответственных унифицировано: снятые назначения не восстанавливаются из устаревших ID. Возможны несколько ответственных для уроков, режимных записей и мероприятий.
4. При создании параллельного занятия исходное «весь класс» становится подгруппой a, новое — b. Проверка каждого ответственного сохраняется; независимые ресурсы двух подгрупп не создают конфликт класса.
5. Сохранение проверяет даты, интервалы, ID и ссылки. Новый документ записывается целиком; при отказе setItem прежнее состояние не заменяется. Черновики урока/мероприятия сохраняются при ошибке записи.
6. После успешного сохранения форма сразу переходит в состояние сохранённой записи, убирается временная карточка черновика. Ручной ввод времени имеет минутный шаг.
7. Добавлены 27 проверок без внешних зависимостей. Архитектура, формат и ограничения описаны в ARCHITECTURE.md.
