# Школьный планировщик «Аспект»

Адрес: https://g-spitfire.github.io/tracker/school-aspect/

Самостоятельное HTML-приложение координатора школы: редактирование расписания и событий, проверка конфликтов, печать дневного расписания в PDF. Начальное расписание пустое; координатор добавляет занятия сам.

## Запуск

Откройте приложение в браузере. Сервер для обычной работы не требуется. На GitHub Pages приложение будет доступно по адресу выше.

## Данные

Изменения и настройки хранятся локально в браузере на текущем устройстве. Серверной синхронизации между компьютерами нет. Очистка данных браузера может удалить расписание; используйте экспорт/резервную копию, доступную в настройках.

PDF формируется из браузера через печать / сохранение в PDF.
