# Аспект

Веб-приложение координатора образовательной организации для составления и изменения расписания.

**Приложение:** https://g-spitfire.github.io/tracker/school-aspect/

## Возможности

Единое расписание групп, уроки, перерывы и мероприятия, назначение нескольких сотрудников, помещения и подгруппы, предупреждения о конфликтах, отсутствия и замены, копирование дня/недели, резервное копирование и восстановление. Для передачи расписания используется снимок экрана; PDF-экспорт не требуется.

## Справочники

«Сотрудники», «Группы», «Помещения», «Уроки», «Перерывы». Мероприятия имеют свободное название и не имеют отдельного справочника. Сотрудники, включая преподавателей и сопровождающих, ведутся в одном разделе.

## Хранение

Данные находятся локально в браузере. Аккаунтов и синхронизации между устройствами нет. Перед очисткой браузера или переносом на другой компьютер создайте резервную копию через настройки.
