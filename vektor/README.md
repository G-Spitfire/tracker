# Вектор

Приложение для Матвея: задачи, проекты, школа, цели, привычки и статистика. Основной файл — `index.html`; стили и интерфейс школьных оценок находятся рядом. Общий модуль Firebase расположен в `../shared/school-cloud.js`.

Канонический адрес: https://g-spitfire.github.io/tracker/vektor/

Задачи, проекты и настройки хранятся в localStorage. Не меняйте ключи хранения и формат резервной копии без обратимой миграции.
