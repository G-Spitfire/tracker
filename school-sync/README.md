# Синхронизация электронного дневника

Этот каталог содержит Mac-сторону интеграции приложения «Школа»: `publish.py` нормализует локальный снимок, шифрует его и публикует в отдельную ветку GitHub.

## Рабочая схема

1. Локальный сборщик получает данные из электронного дневника Санкт-Петербурга.
2. Исходный файл `~/school-diary-data.json` остаётся на Mac.
3. `publish.py` проверяет и нормализует данные обоих учеников.
4. Снимок шифруется AES-256-GCM. Ключ выводится из пароля через PBKDF2-HMAC-SHA256 (600 000 итераций).
5. В ветке `school-data` хранится только `data.enc.json`. Это отдельная orphan-ветка без исходников приложения.
6. `school-simple/school-sync-client.js` загружает файл, расшифровывает его в браузере и хранит снимок и CryptoKey в IndexedDB.

## Защита данных

- Пароль шифрования хранится в macOS Keychain под сервисом `SchoolDiarySync`.
- Случайная 16-байтовая соль хранится локально в `~/Library/Application Support/SchoolDiary/encryption.salt`.
- Пароль не передаётся в аргументах командной строки и не хранится в репозитории.
- В браузере сохраняется неэкспортируемый CryptoKey; пароль в открытом виде не сохраняется.
- В GitHub отправляется только зашифрованный файл. Если репозиторий публичный, сам шифротекст доступен для скачивания. Конфиденциальность зависит от сильного уникального пароля не короче 16 символов.
- Не удалять и не пересоздавать файл соли без отдельной процедуры миграции: это лишит совместимости с ранее опубликованными снимками и сохранённым ключом браузера.

## Формат данных

- `marks` — основной источник записей об оценках. Оценки из `lessons[].estimates` сохраняются как детали уроков и не дублируются в списке оценок.
- Для оценки используется числовое значение `estimate_value_name`; значения вне диапазона 2–5 пропускаются.
- Домашние задания остаются привязанными к урокам. Поскольку подтверждённая дата сдачи в источнике не обнаружена, интерфейс оценивает её по следующему будущему уроку того же предмета. Это предположение, не официальный срок.
- Пустые исходные списки оценок или уроков для любого ученика блокируют публикацию, чтобы не затереть последний снимок неполными данными.
- Расписание передаётся отдельно и используется для календаря и расчёта предполагаемых сроков домашних заданий.

## Размещение и запуск

Код публикации находится в репозитории: `school-sync/publish.py`. Рабочий локальный сборщик, профиль Chrome, LaunchAgent и журналы расположены вне GitHub в служебной папке macOS; их содержимое нельзя проверить по одному только репозиторию.

Однократная настройка пароля (из клона репозитория с установленной зависимостью):

```bash
python3 -m pip install -r school-sync/requirements.txt
python3 school-sync/publish.py setup-secret
```

Публикация:

```bash
python3 school-sync/publish.py --repo /путь/к/клону/репозитория publish
```

Скрипт использует отдельный изолированный Git-репозиторий в `~/Library/Application Support/SchoolDiary/publish-repo`. Он не переключает ветки и не удаляет файлы в основном рабочем клоне; публикация выполняется только в `school-data`, не в `main`.
