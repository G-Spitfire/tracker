# WordScene Next — экспериментальная отдельная версия

Папка `wordscene-next/` полностью независима от оригинала `wordscene/`. GitHub Pages: https://g-spitfire.github.io/tracker/wordscene-next/

## Изменения после повторного аудита (1 ноября 2026)

- **Скорость:** ускорение показывается только после двух корректных измеренных проходов **без ошибок**. Ошибки и прерывания исключают похвалу за скорость. После минимум трёх проходов, когда два последних чистые, при продолжающемся ускорении предлагается ещё один (но ребёнок может перейти дальше). После пятого прохода дальнейшее ускорение не блокирует переход. Измеряется время до открытия ответа, а не речь; это ориентир, не соревнование.
- **Дневной план:** обязательные повторения небольшими порциями по 15 слов. После 15 проверенных слов можно перейти к максимум пяти новым при оставшемся долге. Если просроченных слов не меньше 45, а успешность проверок за последние 7 дней ниже 70% (при минимум пяти проверках), новые временно не предлагаются. При отсутствии просроченных слов сохраняется обычная подборка из пяти новых.
- **Детский отчёт:** «Новых слов сегодня», «Знакомых повторено сегодня», «Всего изучено», «На редких проверках», «Трудных», «Проверок за неделю». Недельная диаграмма считает уникальные изученные или повторённые за день слова; доля успеха считается по итогам проверок знакомых слов.
- **Взрослая резервная копия:** кнопка скачивания WordScene Next JSON и выбор файла для восстановления. Перед заменой требуется подтверждение; предыдущий локальный прогресс временно архивируется в отдельном ключе. Импорт оригинального WordScene не поддерживается.
- **Отличительная иконка Next** на домашнем экране (PNG 180, 192, 512). Размеры кнопок/подписей поправлены, озвучивание использует английский системный голос, если доступен.
- **CI:** `.github/workflows/wordscene-next-tests.yml` проверяет JS и тесты только для изменений Next.

## Безопасность и ограничения

- Прогресс Next: `localStorage["word-scenes-next-lab-v1"]`. Оригинал использует другой ключ и не трогается.
- **Облачное резервирование пока не включено:** действующие Firebase Rules и пользовательский сценарий на iPhone ещё требуют отдельной проверки. Ручная копия не автоматическая; её нужно периодически скачивать и хранить вне устройства.
- Содержимое файлов JSON содержит учебный прогресс, не передавайте его посторонним.
- При потере/очистке данных браузера без скачанной копии прогресс может быть утрачен.
- Тесты не заменяют проверку iPhone Safari: звучание английского, мелкие экраны, офлайн, ввод с клавиатуры, прерывание и восстановление.

## Запуск проверок

`node --test wordscene-next/tests/*.test.cjs`

`node --check wordscene-next/*.js`

Оригинальная папка, Firestore Rules и другое содержимое репозитория не изменялись.
