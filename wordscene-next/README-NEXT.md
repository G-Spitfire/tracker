# WordScene Next — экспериментальная отдельная версия

Папка wordscene-next/ независима от оригинала wordscene/. GitHub Pages: https://g-spitfire.github.io/tracker/wordscene-next/

## Поток карточек

- Новые слова выдаются подборками по пять. Ребёнок знакомится с изображением, переводом, ассоциацией и произношением; затем каждое слово проверяется по одному разу в обоих направлениях.
- Знакомые слова выдаются порциями до 30 уникальных слов. Для сохранения интервального расписания каждое слово проверяется в обоих направлениях, поэтому порция из 30 слов содержит до 60 карточных показов.
- Ошибка не останавливает проход. В повторении ошибочная карточка может вернуться один раз ближе к концу очереди.
- Уже пройденные слова исключаются из следующих обычных порций того же занятия, в том числе после паузы.
- Письменная практика доступна отдельно и не блокирует завершение новой подборки.
- Большая очередь, дневной объём и скорость воспроизведения не блокируют новые слова или переход к следующей карточке.

## Данные и ограничения

- Прогресс Next хранится в localStorage с ключом word-scenes-next-lab-v1; оригинал использует отдельный ключ.
- Формат данных слов и алгоритм интервалов не меняются. Сессия дополнена версией потока карточек и списком уже пройденных слов; старые незавершённые занятия преобразуются при восстановлении, а оставшаяся письменная практика после устного этапа становится добровольной.
- Незавершённая карточка и список уже пройденных слов сохраняются для восстановления.
- Прогресс локальный. Ручную копию нужно хранить отдельно.
- Автоматические проверки не заменяют проверку на реальном iPhone/Safari.

## Проверки


Запуск тестов: `node --test wordscene-next/tests/*.test.cjs`
Проверка синтаксиса модулей: node --check wordscene-next/*.js

WordScene, Firebase Rules и другие приложения не изменяются.
