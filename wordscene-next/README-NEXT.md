# WordScene Next — экспериментальная отдельная версия

Создана на основе WordScene 16.6. **Оригинальная папка `wordscene/` не меняется.**

- Рабочий каталог тестовой версии: `wordscene-next/`.
- Её собственное хранилище: `localStorage["word-scenes-next-lab-v1"]`.
- Прогресс из оригинального WordScene и старых версий не импортируется.
- Firebase и основная облачная синхронизация оригинала не затронуты; новая версия пока сохраняет данные только локально в браузере.
- После первых 15 законченных повторений за день разрешается до пяти новых слов при незавершённой обязательной очереди. Если очередь пуста, ограничение не действует; расписание и интервалы существующих слов сохраняются.
- Появились «Успехи»: освоенные, на редких проверках, проверенные сегодня, трудные слова; недельная диаграмма; доля успешных первых ответов.
- После прохода показываются скорость и динамика. Неверные/прерванные измерения исключаются из сравнения. Автоматического завершения или таймера-гонки нет.
- Озвучка — системная Web Speech API по нажатию, без платного сервера. При проверке кнопка доступна только после открытия ответа.
- Кэш и PWA-ярлык отделены от оригинальной версии.

## Проверка перед публикацией

`node --test wordscene-next/tests/*.test.cjs`

Тестировать на синтетическом прогрессе и в отдельном профиле Safari. Отдельно нужны проверки iPhone: звук, размещение основных кнопок, виртуальная клавиатура, офлайн, восстановление сессии, расписание на границе суток и понятность детской статистики. Тесты и синтаксические проверки не заменяют проверку интерфейса на устройстве.

Пока изменения находятся в feature-ветке. Сайт `/wordscene-next/` станет доступен на текущем GitHub Pages только после явной публикации файлов, не до неё.
