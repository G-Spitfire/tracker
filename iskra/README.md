# Искра

Приложение для Полины: детский трекер привычек, звёзд и достижений со школьными оценками. [Открыть Искру](https://g-spitfire.github.io/tracker/iskra/).

## Что умеет

- Показывает привычки на сегодня и их расписание по дням недели.
- Полина сама может выбрать идею привычки или придумать свою, отметить выполнение, пропустить день, изменить расписание и убрать привычку из активного списка. Необязательное время задаётся там же; напоминания приложение не отправляет.
- При удалении из активного списка прошлые отметки и звёзды сохраняются; привычку можно вернуть.
- Хранит историю, уровни, достижения и выбранное оформление.
- Показывает школьные оценки из Firebase.

## Данные и доступ

Привычки, отметки, профиль, звёзды и достижения хранятся локально на устройстве. Перед сохранением делается резервная копия. Родительский раздел не управляет привычками; экспорт и восстановление JSON находятся в разделе **«Профиль → Для родителей»**. PIN-проверка удалена; настройки дневника и резервная копия доступны на этом устройстве без PIN.

Оценки загружаются из Firebase через общий модуль [`../shared/school-cloud.js`](../shared/school-cloud.js). При желании можно отдельно включить офлайн-копию оценок в браузере; она не шифруется. Синхронизации привычек и звёзд между устройствами нет.

Перед переустановкой или переносом устройства сохраните JSON-копию и проверьте её восстановление. Подробности хранения и синхронизации — в [общем описании данных](../docs/data-and-sync.md).
