# Искра

Приложение для Полины. Основной файл — `index.html`; стили и интерфейсные сценарии находятся рядом. Графика — в `assets/`. Школьные оценки загружаются через общий модуль `../shared/school-cloud.js`.

Канонический адрес: https://g-spitfire.github.io/tracker/iskra/

Ключи localStorage, история отметок и формат резервных копий сохраняются при изменениях. Перед переносом или переустановкой приложения данные остаются на том же домене; для переноса на другое устройство используйте резервную копию внутри приложения.
