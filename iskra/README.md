# Искра

Приложение для Полины: ежедневные дела, звёзды, достижения и школьные оценки. [Открыть Искру](https://g-spitfire.github.io/tracker/iskra/).

## Что умеет

- Показывает дела на сегодня и расписание; ребёнок отмечает выполнение или пропускает дело. Случайную отметку можно отменить.
- Начисляет звёзды за дела, полный день и выбранное дополнительное занятие. Дополнительное занятие не влияет на бонус за обязательные дела.
- Хранит историю, уровни и достижения; позволяет выбрать оформление.
- Показывает оценки из школьного дневника. Родительские настройки находятся отдельно от детских экранов.

## Данные и доступ

Дела, отметки, профиль, звёзды и достижения хранятся локально на устройстве. Перед сохранением делается резервная копия. Ручной экспорт и восстановление JSON доступны в разделе **«Я → Для родителей»**; доступ защищён локальным PIN. PIN ограничивает доступ к экрану на устройстве и не является серверной авторизацией.

Оценки загружаются из Firebase через общий модуль [`../shared/school-cloud.js`](../shared/school-cloud.js). При желании можно отдельно включить офлайн-копию оценок в браузере; она не шифруется. Синхронизации дел и звёзд между устройствами нет.

Перед переустановкой или переносом устройства сохраните JSON-копию и проверьте её восстановление. Подробности хранения и синхронизации — в [общем описании данных](../docs/data-and-sync.md).
