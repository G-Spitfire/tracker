# Форма 2.0 — программа трансформации (черновая версия)

Ветка разработки: `forma-v2-transformation`. Основная версия в `main` не изменена.

## Новая программа

Старт 23.11.2026, горизонт 26 недель. Сценарий с двумя посещениями DDX: A (дома), B (DDX верх), C (DDX ноги). Сценарий с одним посещением: A (дома), D (дома), E (DDX всё тело).

Добавлены пять шаблонов упражнений с диапазонами повторений и временем отдыха, учёт рабочего веса в каждом подходе и новая независимая локальная база `forma_v2_20261123`. Старые записи не импортируются; удаление старого ключа `forma12_v1` предлагается пользователю отдельно и требует подтверждения.

## Пока не завершено

- Настраиваемое расписание недели и корректная автоматическая рекомендация следующей тренировки для обоих сценариев.
- Адаптационный объём первых недель, прогрессия и контрольные точки каждые четыре недели.
- Графики силовых результатов с учётом рабочего веса (существующий график пока показывает повторы).
- Проверка и улучшение редактора программы, резервного копирования и восстановления с пятью шаблонами.
- Проверка корректности таймеров, офлайн-обновления, узкого экрана iPhone и сценариев сброса данных.

**Не объединять с main до завершения тестирования.**
