# Форма — личный трекер тренировок

Адрес: https://g-spitfire.github.io/tracker/forma/

Приложение для 12-недельной программы тренировок А, Б, В и дополнительной Г. Упражнения можно заменять при хорошей погоде; доступны подсказки по технике.

Возможности: запись повторений по подходам и точного времени каждой отметки, старт и завершение тренировки, таймер отдыха, журнал, вес, обхват живота, прогресс и ежедневная отметка ОФП.

## Установка на iPhone

Открыть ссылку в Safari → «Поделиться» → «На экран Домой». Сайт работает без сервера приложения; после первого успешного открытия поддерживается офлайн-кэширование через service worker.

## Данные и конфиденциальность

Данные сохраняются **только в localStorage браузера на данном устройстве** (ключ `forma12_v1`). Они не передаются ни в GitHub, ни в ChatGPT автоматически. Для передачи на анализ есть текстовый отчёт, JSON и CSV. При смене устройства или очистке данных браузера требуется восстановить ранее экспортированный JSON.

Другие приложения в репозитории не изменяются. Бэкенда, аккаунтов и серверной синхронизации нет.

## Оформление и обновления

Светлая палитра «Графит и кобальт»: фон `#F5F6F8`, белые карточки, графит `#172132`, акцент `#245CDB`. Палитра применяется также к таймеру, графикам, отметкам и иконке.

Иконки PNG имеют реальные размеры 180×180 и 192×192; SVG остаётся масштабируемым. Офлайн-кэш имеет префикс `forma-tracker-`: при обновлении удаляются только старые кэши «Формы», кэши других приложений не затрагиваются.
