# Покер с нуля

[Открыть сайт](https://g-spitfire.github.io/tracker/poker/)

Интерактивная инструкция к семейной игре в техасский холдем без денег. Версия перенесена из Sites без изменения правил и сценариев.

## Содержание

10 разделов, 25 страниц: подготовка, личные и общие карты, все комбинации, сравнение рук и ничья, маркер и блайнды, четыре круга, действия и ставки, вскрытие, особые ситуации и памятка. Все страницы доступны сразу, обязательных тестов нет. Учебная раздача находится отдельно и открывается по желанию.

Интерактивные примеры: перемещение маркера, открытие общих карт, сравнение рук и расчёт доплаты. Есть поиск по правилам.

## Файлы и публикация

- `index.html` — разметка и стили.
- `guide.js` — содержание и взаимодействия.
- Сборка, сервер, внешние библиотеки и API не нужны. GitHub Pages публикует каталог `/poker/` из основной ветки репозитория.
- Основная компоновка рассчитана на небольшой ноутбук; предусмотрены планшет и телефон.

## Сохранение

В localStorage сохраняются `pokerGuideReadV2` (просмотренные разделы) и `pokerPracticeDoneV2` (завершение примера). Записи остаются только в текущем браузере. При переходе с адреса Sites на GitHub Pages отметки автоматически не переносятся: это разные сайты. Сама инструкция доступна без отметок.

Личные записи и содержимое localStorage в репозиторий не включены.
